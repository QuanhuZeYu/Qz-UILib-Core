Noto 的八个 TTF 内嵌 `Copyright 2012 Google Inc. All Rights Reserved.`，OpenType name ID 13 为 `Licensed under the Apache License, Version 2.0`，ID 14 为 `http://www.apache.org/licenses/LICENSE-2.0`。本发行依此明确授权保留并分发原始字体，不改写字体名称、版本或许可元数据。

`manifest.json` 记录每个文件的取得来源与固定提交。`roman`、`sans` 中原样保留的 `OFL.txt` 和 `METADATA.pb` 是同次取得的上游材料，其 OFL 标签与这些旧 TTF 的内嵌声明不同。本发行采用上表所列的 Apache 2.0 授权；这些来源材料不替代实际字体的授权声明。
