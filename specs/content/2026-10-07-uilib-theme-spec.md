# UILib 主题与标准控件规格

状态：已确认模块规格；与核心规格共同构成项目规格体系，仅定义本模块职责。

共同状态、布局、生命周期、输入与平台边界遵循[核心职责规格](<../2026-10-07-uilib-core-contract-design.md>)；按职责选择规格见[规格入口](<../README.md>)。

语言事实、翻译键、参数、资源失效和翻译结果语义由[语言与翻译规格](<2026-10-07-uilib-localization-spec.md>)定义；本模块定义文案在控件中的布局和交互，不重复翻译合同。

## 默认现代视觉

UILib 正式页面和案例默认采用统一的现代 shadcn 风格，新增或重构页面沿用，无需逐页重申。字体、角色色、间距、圆角、按钮层级、输入、焦点、禁用、选中与状态反馈来自共同视觉来源；页面只决定业务组织与必要语义差异，不各自复制默认值。

默认局部 UI 字体使用随包无衬线及现有文字覆盖候选，不改应用的 `font.candidates`；调用方显式字体、字号和主题声明仍有效。浅深色保持同一层级与操作含义，窗口/字号变化保持关键操作可达。同族标准控件共用文案策略、完整提示与状态反馈；组合动作由唯一标准动作根持有名称、焦点、激活、命令资格、选中反馈及截断后的完整名称提示，调用方只提供可读名称、子内容、意图与 `selected`，不持有进度或时钟，不产生额外焦点或闲置内部状态。

## 1. 全局主题选择

主题模块声明应用级 `ui.theme`，YAML 取值为 `light` 或 `dark`，缺省 `light`；非法值沿配置核心完整校验报错，不半发布。MC 与桌面分别由宿主唯一 `ConfigSession` 持有并使用实际配置路径，不创建第二主题文件或跨应用全局单例。加载、应用和重载后，消费默认主题的页面随变化更新；保存成功后下次启动加载同一选择。

页面上下文提供所属状态域的主题选择和标准主题派生；独立页面域通过状态通知递交应用事实，不直接跨域借用配置 Signal。呈现订阅归页面，关闭页面只释放自身绑定，不结束宿主持有的主题配置。页面和控件可显式派生局部样式或标明为预览的主题演示，默认选择来自全局配置，新的全局发布使普通演示恢复到该值，不把局部演示保存为全局设置。配色派生保留原字体与间距声明来源及密度、尺寸和动效角色。设置页的主题草稿、预览、应用与保存归[配置页面规格](<../config/2026-10-12-uilib-settings-page-design.md>)。

## 2. 主题与标准控件文案

正式主题派生入口保证有效初值，创建后即可挂载标准控件，后续来源变化继续更新；业务不补算初值或主动刷新。Computed 的首次、写后及派生链读取遵循[核心第 3.1 节](<../2026-10-07-uilib-core-contract-design.md#31-状态独立性与可见性>)；求值可惰性进行。主题入口不自动修复无效业务主题，初始化不能意外将派生内部依赖挂入外层重建 Effect。

标准按钮、现代动作及带名状态控件公开换行、单行省略或允许溢出等文案策略，默认均为换行（`WRAP`），按实际可用文字空间测量、布局与绘制；导航、路径等需单行处由调用方显式选择。语言、字体、主题及空间变化自动适配，业务无需访问内部子节点或布局后补宽度。

标准单行字段可声明响应式空态提示，仅在真实显示内容为空且没有组字时绘制，不参与草稿、提交、选择或复制，也不覆盖组字。字体、文案、空间及资源换代更新提示。字段可选择无边框呈现用于复合表面，真实 caret、选择、编辑和输入语义仍相同；既有工厂默认保留边框。

逻辑焦点与显示焦点线索分开，保持唯一路由权威。标准按钮经 Tab 导航或键盘激活时显示焦点框；主键点击仍取得逻辑焦点，普通按钮不显示键盘焦点框，移动指针本身不改变输入方式。文字输入控件无论点击或键盘聚焦都保持光标、选择及编辑线索。显式焦点请求和模态返回沿当前输入方式呈现，失活/卸载按现行规则释放焦点，不能保留第二份可输入目标。

标准按钮默认参与 Tab 导航，点击取得焦点；当前合法焦点按钮用 Enter 或空格激活，一段按压仅一次，repeat 不重复执行业务。禁用按钮不取得焦点或激活。此默认不改变普通声明节点；按钮作者可显式修改焦点资格，点击聚焦及明确保焦动作沿核心第 6.2 节执行。标签不参与焦点导航。

默认换行下自然高度随内容增长；明确尺寸与最大高度受既定规则约束。空间受限放不下时，非溢出策略仅绘制完整行并标示省略；连完整行或省略标示都放不下时不绘制残行，仍保留完整文案。截断的标准动作与带名状态控件在当前悬停或键盘焦点可见时即时显示被动完整文案提示，在当前 viewport 内放置；提示不参与输入、模态或布局，空间不足仅裁剪提示区，不改变原控件尺寸、字号或焦点。两者均离开来源且指针离开所属提示内容后提示消失，显式保焦动作按实际焦点判断；提示不额外维持来源焦点。此默认不推广到所有控件。

## 通用 Tooltip

Tooltip 绑定原触发器，不替换其控件、动作、UUID 或焦点，支持显式或页面默认主题入口；内容可声明多行、TextContent 属性及独立快捷键说明，说明不代替正文关键错误，不含交互按钮或编辑框。文字省略、仅标记/图标名称、物品提示和显式说明共用页面唯一协调者，同时只显示一个提示，显式内容优先，物品 typed/富文本保持原声明与资源代际。

默认悬停即时显示，允许配置打开/关闭延迟和同组快速切换期限；键盘可见焦点即时显示。新指针进入或键盘焦点变化按真实触发切换，同批新键盘焦点优先；纯重排不抢当前有效提示。点击或 ESC 关闭后，原 hover/focus 未结束时不立即反弹。隐藏、禁用、完全裁剪、卸载、范围切换或页面结束撤销旧等待与显示，重挂不复活旧记录。

内容支持四个物理侧、逻辑 start/center/end、offset、箭头和宽度约束，边界不足优先反侧再平移，超长内容限于当前 viewport；RTL 只作用逻辑对齐。鼠标可从来源移向提示内容保持可读，观察来自唯一路由器和同代正式几何，不截获下方点击/滚轮或建立可输入层。禁用按钮通过合法中性来源说明原因，不使被禁用按钮可激活；键盘查看原因需另有合法焦点来源。

主题、字体、文字、当前源盒及窗口变化更新同一提示的度量与定位；时间推进复用已有有限呈现队列，静止不永久 tick、不为每提示创建线程。ESC 有限例外沿核心第 6.1 节，普通纯通知合同保持。

## 通用范围Slider

范围声明包含有限最小/最大值、正步长、外部当前值、可用资格、可选缓冲区间和来源代际；键盘步长可独立于拖动细分。调用方通过显式或页面默认主题入口分别声明预览变化与最终提交回调，不隐式代选提交策略；控件只保存有限当前预览，不成为领域值权威。普通模型从自身正式盒内建立唯一指针捕获，拖出后可继续夹取预览。

显式启用弹性时，盒外可见且未被祖先裁剪的 thumb 圆形区域也可起拖；回弹途中重新拾取，停止旧释放，从当前可见位置与预览值连续接管。盒外空白不扩大为滑块命中区域，新点击仍交给该处原有控件。弹性形变与动效限制归[动效规格](<../scene/2026-10-17-uilib-motion-spec.md>)。

释放使用最新声明完成一次提交，重复 UP、取消、禁用、卸载及代际变化不能提交旧预览；ESC 先取消有效捕获。键盘方向、Home/End 和 Page 沿当前焦点与范围发布同一意图。主题、字号和当前空间沿原测量/绘制依赖更新，不逐帧读外部设备或另建输入线程。

## 3. 复选框与图标动作

标准复选框、开关与单选选项同属符号状态控件族：复选框声明 UNCHECKED、CHECKED、MIXED 三种显示状态，写入意图与来源状态分开（CHECKED 激活请求 false，UNCHECKED/MIXED 激活请求 true，不隐含全选范围或业务集合）；开关与单选组归[标准状态控件规格](<../scene/2026-10-18-uilib-state-controls-spec.md>)。禁用、点击聚焦、Tab 与 Enter/Space 激活沿标准按钮的共同输入合同，可用资格取自真实 `enabled` 声明，不从文字色与禁用色相等反推；选中与状态反馈只失效绘制，不重新测量名称。

状态控件可带名称（文案策略与截断提示同第 2 节）或仅显示标记；图标动作只显示明确的向量符号。两者都要求完整可读名称，仅标记/图标模式在当前悬停或键盘焦点时即时显示被动名称提示；提示不改变布局、输入和焦点。字号、主题、名称和宿主空间变化动态更新；命中区域包含正式 padding，不依赖缺字占位或固定字号。

图标动作的星标、归档、邮件、导航、搜索等符号是通用视觉内容，具体业务动作或共享命令由调用方提供；次级图标与父级主体分别激活，不由控件推断冒泡或批量业务。标记可响应式变化（例如星标轮廓/填充），保留控件、焦点与命中身份，单纯标记变化只失效绘制。复合动作可消费同一图标的纯装饰节点，装饰不建立额外动作或焦点目标。有限标准图标与圆角通过实际像素 coverage 平滑边缘，载荷仍是正式不可变 PaintPlan；缓存只持有限形状/大小，不持节点或主题。

## 4. 默认动效与被动悬停

控件可在正式绘制扩展声明有限过渡的下一次绘制时刻；绘制只读呈现值，宿主正常帧在到期时仅更新 PaintPlan，过渡结束恢复静态计划复用，不启动逐控件线程或每帧全量轮询。卸载/关闭后不继续持有更新任务；过渡不改变业务值、输入身份或独立布局事实。

主题提供标准控件的反馈及空间动效角色（按钮、现代表面、图标、复选标记、单选圆点与页签指示用短而平稳的反馈角色，开关拇指用空间角色）；优先级为用户动效限制 > 局部 `feedbackMotion` 覆盖（含空间拇指） > 主题角色。正常、减少及关闭限制、有限过渡反向缩时、预乘颜色、弹簧续接与挂载时间合同统一归[动效规格](<../scene/2026-10-17-uilib-motion-spec.md>)。显式布局、存在性及手势释放不由主题默认隐含开启。

被动悬停可作为挂载期呈现来源：唯一路由器按当前有效几何、裁剪及输入范围发布命中所属子树的进入/离开，订阅者可声明进入等待；离开和卸载立即结束等待与所属呈现。它不新增点击、捕获、焦点或第二命中区域；纯绘制仍只读，呈现映射在声明准备阶段执行。

## 5. 本地文件选择

文件选择器组合 UILib 正式场景、输入框、按钮、滚动区及模态范围，在所属页面窗口内呈现，支持显式或页面默认主题入口。目录访问使用 Java 标准文件 API；不委托 Swing、AWT、JavaFX、游戏控件或原生文件选择对话框。调用方提供初始目录并接收选中的文件或取消意图，业务决定后续用途。

选择器采用 shadcn 式中性色、轻边框和圆角表面，标题、说明、路径、目录内容及操作分区清晰。文件/目录以图标与名称区分，主确认与次级导航/取消有明确层级；面包屑显式采用单行省略，目录条目保留名称按钮热区、外表面共享反馈与元数据非动作。默认界面文字使用随包无衬线字族及已有文字覆盖候选；这是局部 UI 字体声明，不修改也不跟随应用默认候选配置，调用方显式字族/候选仍按其主题声明使用。浅深色、声明字号/字族和窗口变化沿正式测量与失效更新。

用户可从根目录或盘符、上一级及路径输入导航，浏览目录、选择并确认任意扩展名的普通文件。中文、空格和加号保留实际路径身份；确认时重新核验文件。列表高亮、路径草稿与待确认目标保持一致；编辑路径后不再以旧选择冒充当前目标。核验或导航反馈只影响对应的当前请求与提交；核验 A 期间继续编辑 B，A 的迟到成功不能关闭选择器或提交 A。空目录及不可访问或不存在的路径在选择器内反馈，保留继续导航与取消入口。取消按钮或 ESC 只结束选择器，不提交文件；调用方原有状态保持。模态期间后台不接受指针、键盘与文本输入，返回沿共同焦点范围合同处理。

目录默认置于普通文件之前，组内采用名称自然升序；数字段按数值比较，大小写等价时以原名称和实际路径稳定区分。排序覆盖整个当前目录的逻辑顺序后分批呈现，不仅排序可见页。前后翻页沿有序边界扫描，只保留明确页预算与有限探测项，不无界缓存整个目录；目录外部变化后显式刷新重读事实。

名称搜索在当前目录全范围执行，Enter 提交已完成的文字，不在组字中扫描；清除立即恢复无名称过滤的结果。调用方可声明类型筛选预设，默认及显式“所有文件”仍允许任意扩展名，类型筛选不隐藏可导航目录。名称升降、类型、大小与修改时间排序同属一次不可变查询代际，目录保持在前；元数据只由目录 worker 读取，失败显示未知，不以 0 伪装。

前后导航最多保存 64 项目录/根范围、查询顺序、页边界、合法选择及滚动锚点；分叉清除前进分支。刷新重新读取并保留仍合法的选择/位置，目标消失则解除。路径层级与上级入口共享导航；列表当前焦点上的方向/Home/End/Page 移动与显露、同批输入时刻的普通文字前缀跳转沿唯一焦点/编辑路由，Enter 沿原按钮选择语义，不建立额外 Tab 循环或截获编辑框/组字。矮窗优先路径、搜索、列表和确认，说明与层级可收敛。

设置添加字体来源复用同一选择器，只回填独立路径草稿；仍须用户显式追加、应用和保存。取消保持原草稿，内层 ESC 只结束选择器，调用方主题、校验和来源配置仍由原 owner 拥有。

目录读取不阻塞宿主输入与呈现；请求、结果和工作归当前选择器生命周期，导航、取消或卸载后迟到结果不覆盖当前目录或恢复已结束界面。工作队列、目录结果存储及挂载行有明确上限，大目录分批浏览。导航、重新打开及显式刷新重新读取文件事实，不依赖每帧重扫；主题、字体与窗口空间变化沿正式控件和布局更新。

验收使用实际目录和正式输入路径，覆盖目录与上级导航、分页、刷新、任意扩展名文件确认、路径错误、取消及 ESC、模态隔离、窗口变化与释放。平台专项运行结论仍按实际宿主分别记录。
