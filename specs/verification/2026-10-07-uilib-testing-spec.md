# UILib 测试应用规格

状态：已确认模块规格；与核心规格共同构成项目规格体系，仅定义本模块职责。

共同状态、布局、生命周期、输入与平台边界遵循[核心职责规格](<../2026-10-07-uilib-core-contract-design.md>)；按职责选择规格见[规格入口](<../README.md>)。

## 1. 统一测试自动化应用

测试作者通过统一 TestApplication 定义具名场景，复用初始化、执行、资源释放与结果报告。核心检查按模块归入测试广场，同一目录供页面与无窗口命令入口运行；场景类不各自维护 main 或 Gradle 启动任务。新增检查表达输入、生产链路和可观察预期。

统一的是运行生命周期与使用方式。基类本身只依赖 Java8，不引用 Minecraft、Forge、LWJGL 或自动创建 native/GL 环境。纯逻辑、软件光栅、真实字体、LWJGL2/LWJGL3 与游戏集成通过按需组合的环境组件取得能力；组件维护所属资源与前置条件。字体来源读取及同类宿主初始化集中复用，具体测试保留自己的数据、算法观测和断言。不存在环境时如实失败，不静默跳过或切换宿主。

应用按声明顺序执行场景。初始化、场景或清理失败时保留原始异常及场景身份，以非成功退出暴露；资源按所属作用域逆序释放，清理失败作为附加原因，不覆盖原始失败。只有实际执行且清理成功的场景和应用报告通过；空应用不得报告通过。既有真实回归迁移至此模型，结果仍按对应宿主区分，不把统一运行器的通过外推为游戏、GPU 或性能验收。

测试应用、共享组件与其回归代码位于测试编译单元，不进入正式 UILib 发行或核心 API。重写不得以基类便利为由修改生产职责、替换真实核心机制，或修复原版游戏自身内容。共享 TestApplication、测试工具、中性 scene fixture 与广场声明由 Core 独立测试产物提供；Platform 和 Minecraft 的测试通过依赖复用，不复制源码，也不让 Core 的构建反向依赖这些宿主。

专用性能压测的负载、采样口径与基线验收归[性能压测广场规格](<2026-10-14-uilib-performance-testing-spec.md>)。

## 2. 共享测试广场

测试广场由参考案例和核心验证组成。参考案例包含 Gmail 收件箱、Shadcn Admin 正式配置、dnd-kit 交互、[SimpleBar 滚动区](https://grsmto.github.io/simplebar/examples/)、[声明式动效](<../scene/2026-10-17-uilib-motion-spec.md#9-可观察验收>)、[媒体播放](<../content/2026-10-16-uilib-media-spec.md>)，以及各正式控件规格认可的表格、树、状态表单、标签页、路径、密度与场景检查页。核心验证从同一目录进入，展示必要检查及其实际结果。旧知识库、生产计划、项目表单、活动中心、数据报告与旧操作页及其专属样本移除，不保留隐藏入口。

无平台自动化、Desktop 与 Minecraft 使用同一共享声明；Minecraft 的版本与实例组合归[多版本宿主规格](<../../../Qz-UILib-Minecraft/specs/host/2026-10-18-uilib-minecraft-hosts-spec.md>)。

广场目录、媒体、交互示例、邮箱、配置及独立性能广场共同遵循[默认现代视觉](<../content/2026-10-07-uilib-theme-spec.md#默认现代视觉>)。业务交互参考保留各自操作含义，视觉不再并行还原不同产品的配色/字体；验收逐页包含浅深色与窗口变化，不能用局部弹层截图代替整页一致性。

每次广场运行持有独立状态与逻辑树，页面切换通过正式动态子树声明保留本次运行的页面状态，取消失活页面的输入联系；结束广场释放所有页面和资源，不使用进程静态字段保存编辑状态。导航、初始语言、图像服务及平台专项来源在明确边界接入；共享内容不直接读游戏设置、构造 ItemStack 或调用平台窗口。

参考网址只用于行为与视觉取证，案例运行不依赖公网服务。正式图像、语言、文本与宿主专项能力仍在所属模块验收，样本只归实际消费者的测试资源，不为旧页面继续放入广场附加包。

共享交互场景通过宿主驱动递交正式输入，断言可观察业务结果与内容变化，不直接调用控件回调或修改其内部状态。默认自动验证运行无窗口闭环；Platform 在同一 ScenePageSession 中提供真实字体和 CPU 图像能力。窗口、GPU、OS 与游戏验证保持显式入口，暂停期间不得由 check 或广场核心检查自动启动。恢复设备验收后，桌面沿实际 GLFW 窗口和已安装输入回调取证；MC 经游戏入口部署，启动及实机操作按会话授权执行。结果标明所属宿主和证据。

广场默认进入参考案例目录，各宿主使用同一份页面声明和正式信号、控件、输入路由与 PaintPlan。配置案例直接组合正式 SettingsPage，借用当前宿主的真实 SettingsConfiguration 与同一状态域，不另造模拟配置或第二份表单。

媒体播放页组合正式 SceneVideo、SceneMediaControls 与宿主提供的中性媒体服务，提供来源输入、UILib 自有本地文件选择器和随测试应用携带的示例。用户可选择任意本地视频文件，或输入本地绝对路径、file URI、HTTP/HLS 地址；不以扩展名白名单限制选择，实际无法解码的文件显示原有播放失败反馈。

文件选择遵循[标准控件规格](<../content/2026-10-07-uilib-theme-spec.md#5-本地文件选择>)，在当前广场窗口使用共同场景及模态输入，不依赖外部 UI 工具包或系统文件弹窗。打开选择器期间当前播放继续，取消或 ESC 保留当前会话与来源，确认文件后才换源；宿主只接入初始目录、路径身份及正式媒体服务。

打开来源前不创建播放会话，停止、换源、离开媒体页及结束广场时释放本页拥有的播放资源。来源编辑等本次运行状态继续保留，重新进入后由用户明确打开播放。

共享编译单元只依赖无平台核心，宿主分别供给正式配置、媒体后端与示例来源。共享验证数据由 Core 唯一维护，以独立测试产物按需供 Platform 和 Minecraft 的测试消费，包含参考语料、图像与语言样本、媒体短素材及来源说明；这些数据与测试代码均不进入生产包，也不引入生产反向依赖。专用性能负载仪器继续由性能规格管理，独立于参考案例目录。

测试广场提供统一构建、人工启动与验证入口。各仓保留独立构建，通过正式 Maven 依赖组织 Desktop 测试消费者及 MC 人工附加包；测试代码和资源不进入生产发行。人工入口仍为 desktopGallery，从共享目录选择页面。Core 的 galleryVerify 与 Java21 正式产物检查、Platform 的 galleryVerify 纳入各自 check；不按场景注册数十个 JavaExec，不保留空 test 占位来报告成功。正式桌面设置发行入口及性能压测遵循各自范围。

验收包括共享编译与产物隔离、各宿主入口引用同一输出、参考案例的自动化与真实桌面交互、页面切换后的状态保留与输入隔离、运行实例间状态独立、图像实际像素及关闭释放。MC `/qzcore` 统一进入共享目录；未执行的 MC 画面和专项验收如实说明。

## 3. 核心验证组织与结果

核心算法、状态与生命周期、输入与编辑、集合、配置、内容及媒体的必要检查集中在 src/galleryVerification，按能力分文件维护。删除只验证运行器自身、只比较资源目录或文本快照的测试；合并重复场景和已被实际广场操作覆盖的检查。保留真实故障、关键算法边界、资源归属与失败清理断言，不以保留历史场景数量为目标。

核心验证页列出具名模块，支持运行单项或全部检查，并在点击后立即显示运行状态。检查在独立无窗口环境中执行，结果通过当前 ReactiveDomain 更新 Signal；返回目录保持本次结果，结束广场释放所属执行任务。检查不能阻塞页面输入、直接写挂载节点或重定向进程的 System.out。通过、失败、耗时及实际场景明细在所属模块卡片内查看；原始异常与清理附加原因保持可定位。

页面和命令行使用同一 GalleryChecks 目录与实现。命令入口可以选择模块，但不为每个场景新增启动器；命令执行失败以非成功退出暴露，报告保留模块和场景身份。Core build 的自动检查涵盖 Java8 和 Java21，正式 Jar 的类型、资源和隔离消费仍实际执行；Unicode 字典、无平台媒体会话与视频布局不能只检查 class 存在。

Core 的 gallery 与 core-verification 是独立测试 Maven 产物。gallery 定义共享页面及检查服务接口；core-verification 携带 TestApplication、必要检查、注册信息和共享语料，依赖 Core 与 gallery，Core 生产源码不反向引用这些编译单元。Platform 和 Minecraft 从同版本正式坐标消费；人工测试附加包包含运行核心验证所需的独立测试产物。缺少实现时页面明确报告装配缺项，不产生通过结果。

目录导航回归从 HOME 实际进入并返回全部共享页面，覆盖宽屏、大空间和窄屏，包含项目资源与项目详情中的嵌套 FILL。屏外操作通过原滚动端口及共同几何显露，不修改控件的原 Tab 资格、直接设置滚动结果或调用点击回调。Platform 复用同一导航流程并提供真实字体。
