# 通用命令与范围快捷键规格

状态：正式模块设计，沿已认可的[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)授权实施。本文定义命令与键意图；方向目标选择仍沿核心导航合同及后续所属设计。

## 1. 共享业务动作

页面以一个命令表达可执行条件与业务动作，标准按钮、现代文字/组合动作、图标按钮、菜单和快捷键可直接引用同一命令。可执行条件是可追踪的只读信号；控件通过同一命令入口同步 `enabled` 外观与交互资格，无需拆传 `tryExecute` 并重复绑定 `enabled`。尝试执行时重新读取条件，条件不成立不调用动作；不依赖上次绘制的 `enabled` 快照。命令动作在所属响应域中执行，异常保留原错误，不解释为未消费。

命令不拥有控件、页面、焦点或输入范围，不自动观察或复制业务状态，不建立另一份撤销栈。保存、查询、导航等业务动作不隐含草稿提交、接受、重置或文本历史修改；业务需要普通模板插入时显式调用已有原子编辑入口。已有Runnable按钮和直接业务调用保持原用法，不要求先创建命令。

## 2. 范围绑定与生命周期

快捷键绑定是现有场景节点的声明，注册与释放归该节点的挂载Owner。命令与绑定分别持有：同一命令可以供多个按钮使用，并在业务选择的输入范围绑定。卸载即解除旧注册；重挂建立新挂载联系，不重复触发旧绑定。隐藏、禁用、模态隔离及节点归属变化按当前有效输入资格核验。

快捷键声明明确选择PAGE或MODAL角色。PAGE绑定归当前页面范围，声明可以附在页面根或该页面内已挂载的内容根，以保持设置、邮箱等页面可嵌入工作台的既有组合方式；它不创建新的非模态局部范围或优先级。MODAL绑定明确所属模态节点，只有该节点实际成为唯一当前模态时才参与。角色不随当前modal布尔、父节点或历史状态推断或变化；模态属性关闭但节点继续显示时，该MODAL绑定停止参与，不提升成页面命令。首次尚未激活的条件模态也可以保留MODAL声明。输入范围仍由既有模态与所属层机制决定，不新增输入树、命令焦点或绘制层优先级。非模态普通控件的局部快捷键与全局系统快捷键不在本期范围。

没有活动模态时查询当前页面范围的有效绑定；存在活动模态时只查询该模态范围，不转入后台页面。所属交互浮层沿原逻辑范围参与，不因绘制到另一层产生独立快捷键范围。一个生命周期仍有效但被内层覆盖的范围，不等于当前键输入范围。

同一有效范围内，同一精确键组合只能有一项绑定，重复声明应定位到冲突范围与节点。不同范围可以分别声明同一组合。不能以后注册覆盖、UUID排序或绘制高度作为冲突规则。匹配到绑定即消费本次应用快捷键，即使命令当前不可执行；模态没有该绑定时仍隔离后台页面和同类应用快捷键的宿主继续动作。ESC专用关闭链保持原合同。

## 3. 中性键意图与编辑优先

宿主把原生历史事件转换为中性命名键、当次修饰键、DOWN/UP阶段、重复事实和既有剪贴板端口，经页面原输入队列递交。原生整数键码、设备枚举及操作系统队列只在宿主边界解释；Core不消费原生队列。旧SceneKeyEvent构造默认DOWN，真实宿主也递交UP，不在宿主维护按钮按压或合成click。普通文本、空格、中文提交与带真实来源的组字仍沿原文本接口递交，键意图不从命名键合成字符。

快捷键以一个命名键及精确的Primary/Shift/Alt/额外修饰键集合声明，包含功能键、方向、数字与符号键，不限于Primary+字母。Primary由宿主映射到其主快捷修饰键；primary/primaryShift便利入口保留。没有声明的修饰组合不隐式匹配，也不合成文字或多步键序列。普通可打印键在当前文字编辑目标中仍交原字符来源，不因页级同名键绑定触发搜索等动作；标准编辑命令已经消费时不执行应用绑定。ESC先沿原专用退出链处理。

Core将标准编辑键意图解释为既有编辑命令，经唯一编辑目标与已声明editActivator先处理。编辑已消费即停止，包含复制空选区、空撤销历史、只读修改及无实际文案变化的消费；不能以草稿是否改变判断让渡。Tab、Enter、Space、方向及ESC保留所属编辑、导航和激活合同，不把保存或搜索加入编辑命令枚举。

未映射为编辑命令的应用键也服从当前组字联系。当前有效来源仍等待COMMIT/CANCEL时，UPDATE(active=false)只结束预编辑呈现，不能据此让应用快捷键切换目标；旧无来源组字入口的当前composing状态同样保留输入。失效或结束联系依编辑规格处理，不阻挡后来合法操作。

编辑未消费后，应用命令沿同一输入事件的后续结算执行：键路由在编辑前捕获本次实际输入范围，本事件的状态与Effect先成功结算，再准备当前声明及范围事实。只有原范围仍有效且仍是唯一当前输入范围时，才在该原范围内读取当前绑定和可执行条件并尝试执行；范围改变即结束本事件的应用快捷键及宿主继续动作，不转投新内层或返回后的外层。同一范围内的绑定及条件消费结算后的当前值。关闭页面、范围结束或失败不能使旧继续动作操作后来页面。命令及必要切焦必须先于同批下一文本生效；不另投第二个快捷键事件，不延迟到下一帧。

ESC保持既有捕获、编辑/IME、Tooltip、范围/页面策略及宿主fallback顺序。宿主继续动作只在未消费、当前批成功且原页面仍有效时执行；任何handler或Effect失败都不能被当作未消费。旧edit、editOrNavigate和escape入口继续分别表达原语义，不从旧编辑事件猜测不存在的原键与修饰键。

## 4. 物理按压与旧输入隔离

应用快捷键每段合法fresh DOWN至多执行一次；repeat不重新执行，不因为动作关闭内层模态而在同一按压段转投外层。Core保留已获准的原范围与消费类别；原编辑续段仍要求原焦点挂载，保留/应用段不会变成后来目标的编辑。Tab导航repeat继续逻辑导航并读取当次Shift，不因新字段开启INSERT_TAB而变成编辑。空间箭头导航repeat每次先交当次焦点的编辑/activator；消费后将后续编辑限定到该实际挂载，未消费才继续本次范围的空间导航。组字保留仍优先。标准编辑删除和移动保持重复。按压门只维护物理事实，不拥有业务范围；主Enter与小键盘Enter共享确认含义，保留独立物理身份。

无修饰Space被编辑和应用绑定让渡后，只在原合法click目标建立按压，DOWN显示按压而不激活；UP仍为同一挂载、同一当前范围且从未离开焦点时，结束按压并激活一次。焦点离开再返回、失活、模态覆盖、失焦、事件失败与关闭都会结束旧按压；repeat和没有起手的UP不激活。按压事实复用有限SceneKeyContinuation和原焦点转换核验，标准控件通过共同runtime.pressed呈现，不建立第二路由。Enter保持常规DOWN激活并忽略repeat；带修饰的Space遵循其明确快捷键声明。旧edit/editOrNavigate的原命令含义保持，文字空格始终来自原字符串事件。

开屏或恢复可用性时，旧持键、历史DOWN和repeat不能激活命令；唯一原生消费者耗尽历史并确认真实释放后，新的完整按压才有效。UP、失焦、设备可用性和历史耗尽按原输入适配合同递交；不为每次回调重新假定fresh，不旁读原生事件队列。

## 5. 真实调用方

设置页的“保存到文件”按钮与Primary+S共享命令：未应用的修改存在时不可保存，已经应用且有尚未保存变化时可执行，动作继续调用既有保存流程；其余底部操作、树展开及表格等标准动作控件同样直接消费命令。快捷键不代替“应用”、不隐含确认当前字段；业务失败呈现仍归原模型。

邮箱Primary+F请求现有搜索字段的合法当前焦点，不清查询、不自动全选或提交。搜索组合向页面提供明确命令，不按内部children下标寻找字段；焦点与文本仍由原路由和独立编辑状态维护。

桌面原有重载配置继续动作保留公开入口及页面确认委托；其快捷键先交正式Core键路径，未消费且不受模态/IME隔离时才执行原宿主继续动作。Minecraft现有唯一键盘消费者只负责中性转换，继续按历史顺序和物理释放事实推进，不直连原版控件或另建消费者。

## 6. 验收

| 场景 | 可观察结果 |
| --- | --- |
| 可执行状态变化后立即点击或按快捷键 | 两条入口读取同一当前条件；禁用动作不调用业务，不等待重绘 |
| 页面也声明复制或撤销键，字段无变化或只读 | 原编辑消费优先，页面命令不被误触发 |
| 正常字符、带来源组字及旧组字入口 | 字符不触发应用命令；组字期间应用键不抢焦点或错投迟到提交 |
| 同批行内动作、搜索快捷键、文字 | 后续文字进入当前搜索字段，已成功的切焦不延到下一帧 |
| 页面与内层模态同键、内层禁用或无绑定 | 后台隔离；内层结束的同事件及repeat不触发外层；编辑Effect打开内层后原键不进入新范围 |
| 同范围冲突、隐藏、卸载、重挂及归属变化 | 冲突可定位，旧注册失效，新挂载只生效一次 |
| 开屏持键、旧历史及失焦恢复 | 释放和历史耗尽前不执行，新的fresh DOWN正常执行一次 |
| 编辑、命令或Effect失败与页面结束 | 原错误传播，宿主继续动作不越过失败或操作后来页面 |
| 旧编辑、导航、ESC及Runnable按钮 | 原入口和原使用条件继续有效 |

稳定逻辑通过正式ScenePageSession和统一测试应用观察；实际字体、剪贴板及GLFW历史与按压通过正式桌面运行，Minecraft只按受影响成品组合验证，实机仍遵守会话授权。中性组字来源测试不能替代操作系统输入法桥的真实验收。

## 7. 前端参考与采用行为

[React Aria useKeyboard](https://react-aria.adobe.com/useKeyboard.md)与其[实现](https://raw.githubusercontent.com/adobe/react-spectrum/main/packages/react-aria/src/interactions/useKeyboard.ts)提供精确修饰键和命名键组合，普通目标先处理，快捷键默认不重复且不抢组字。本模块采用这些默认及声明便利度，继续保留原编辑消费、Scene范围和同事件Effect结算。

[Button](https://react-aria.adobe.com/Button.md)、[按钮按压案例](https://react-aria.adobe.com/blog/building-a-button-part-1.md)及[usePress实现](https://raw.githubusercontent.com/adobe/react-spectrum/main/packages/react-aria/src/interactions/usePress.ts)提供完整按压、忽略重复和目标失效取消的参考；Core以DOWN/UP和原挂载许可表达Space释放激活，Enter维持常规按下激活。按钮、菜单和快捷键继续引用同一业务命令。
