# UILib 通用界面组合规格

状态：按用户授权提取现有界面组合，并在共享广场分类展示。

共同状态、布局、输入与生命周期遵循[核心规格](<../2026-10-07-uilib-core-contract-design.md>)；基础排列、模态、编辑、集合与动效仍归各自正式模块。

## 1. 职责

页面提供业务权威、内容来源、校验与操作意图；公共组合承接重复的区域排列、标准控件组合、标签关系和呈现。所有组合进入现有 SceneNode、Signal、SceneControl、PaintCommand 与唯一输入路由，不建立第二份状态、焦点、选择或资源权威。新增公共组合保持 Java8、无平台依赖。

主题、文案、字体、尺寸策略与业务状态均可追踪变化；布局消费当次正文约束，保留子项硬边界，不读回上一帧几何补偿普通排版。外部来源归调用者，组合只清理自己创建的节点、派生与绑定。

## 2. 布局与弹窗

通用排列提供内容换行、居中、叠层、正文剩余空间分配及说明/动作的自适应排列。padding 只算一次，隐藏项不占位，同批测量与排列共同决定绘制和输入。既有居中行与卡片表面复用现行外观能力。

通用弹窗组合标题、正文、页脚、主题表面、尺寸约束、遮罩和关闭请求。初始与返回焦点、嵌套弹层、ESC、退场输入资格沿正式合同；使用者提供初始焦点及关闭意图，弹窗不隐式提交或丢弃草稿。确认与输入情景组合同一外框。正文的滚动策略显式声明，较小视口保持正文和操作可达。

## 3. 字段与搜索

表单字段组合标签、控件、说明、错误及可选附属动作，统一 labelledBy/describedBy；支持上下排列及说明/控件自适应排列。字段接受调用者持有的编辑控件和错误来源，不新增校验状态、提交权威或配置会话。

搜索框复用 SceneTextField/SceneEditState，组合搜索标识、占位文案、清空及正式焦点命令。即时 INPUT 与确认 CONFIRM 策略由调用者选择；清空发布明确意图，查询算法、外部查询同步和结果归调用者。组字、光标与旧提交隔离沿编辑合同。

## 4. 选择、工作区与反馈

通用选择对话框消费稳定键选项、名称、可用状态、当前选择与选择意图，复用正式有限集合、按钮和弹窗。内容选择后是否关闭由业务决定；本地文件选择继续维护目录事实与异步文件核验，文件模式不随本次提取扩大。

主从组合消费调用者给出的并列/单栏策略及详情活动来源，组合列表与详情槽位；窄屏返回发布业务意图，选中值与编辑草稿仍归业务。隐藏或切换沿正式资格终止输入，状态不依赖重新打开页面恢复。

反馈组合提供说明、成功、警告、错误与空态的内容槽位及可选动作。持续或短暂显示显式选择，短暂反馈沿现有 transientValue 与动效作用域；不隐含重试、回滚或业务任务状态机。

分页组合只提供摘要、上一页、下一页及可执行状态，允许总数未知；分页算法、游标、页大小和数据请求归调用者。

### 4.1 浮动通知

页面持有通知区并将其节点声明为持续来源的直属孩子；通知区复用所属层、SceneNotice、稳定键动态子项、transientValue 与声明式动效。Toast 是纯提示区：不抢焦点、不参与 Tab、不消费 ESC，整个分支对指针透明；Notification 是非模态交互区：通过所属层的仅实际目标参与策略，让自己的标准关闭和业务操作按钮参与当前有效范围，正文与留白的滚轮透传后台，不阻断后台，不在出现时主动聚焦。模态覆盖和来源失效沿所属层合同处理。

每次追加产生独立身份，连续追加依序保留，不以最新一条覆盖全部消息。容量由创建者明确提供；超过容量时移出最早的条目，不保留隐藏队列。关闭仅撤下对应条目；执行附属动作先由 SceneCommand 检查一次当前条件，获准后撤下对应条目再执行原动作，不因撤下改变条件而丢失本次许可；条件拒绝时保留条目。纯提示不接受附属动作。

调用方提供可追踪的消息、动作和关闭文案；主题、字号、位置、宽度、边距及间距变化自动更新。位置支持顶部/底部与起始/居中/末端组合，布局依据当前视口求解，不读取旧几何。普通内容与尺寸仍沿核心硬边界和视口裁剪规则。

正时长表示本次挂载中的短暂呈现，零表示保持到显式关闭；内容和主题变化不重启期限。卸载结束短暂通知的观察和推进，重新挂载不重放已结束的短暂通知；持续通知保留逻辑状态。结束后立即失去输入资格，有限退场沿统一存在性动效，永久销毁释放通知区所属资源。通知区只管理呈现，不存业务历史、不增加重试或撤销策略。

共享广场提供被动轻提示、连续堆叠、持续通知、关闭、带动作通知和位置切换，真实路由验证纯提示透明、通知不抢焦点、按钮撤下与期限结束；关闭后不再推进计时。

## 5. 共享广场

HOME 按基础输入、布局与表单、弹层与选择、数据集合、拖放与滚动、内容与媒体、综合应用、验证工具组织可进入的示例。目录由一份页面/分类元数据驱动，已有页面保持可达；已通用化能力有可操作的独立示例，综合应用继续展示真实组合。

示例实际调用正式 Core 公共 API，包含清空/提交、模态取消和返回、错误保留、选择、宽窄切换及分页等可见结果。页面切换保持本次状态，失活页不接收输入，结束释放资源；页面不包含第二份组件实现或平台类型。

## 6. 验收

正式设置、文件选择、媒体与邮箱沿公共组合运行，原有应用/保存、文件确认、播放选择、搜索与分页语义保持。广场从 HOME 按分类进入每项，包含已有组件和新组合，返回保留输入；浅深色、宽窄窗口、Tab/ESC、嵌套模态与关闭释放均取得实际反馈。

Core 完整 build 验证 Java8/Java21 及正式产物隔离，Platform 完整 build 与真实 GLFW 桌面场景验证交互和画面。Minecraft 只验证受影响的构建装配，游戏运行按另行授权。
