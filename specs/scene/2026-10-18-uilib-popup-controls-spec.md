# 选择器与动作菜单规格

状态：沿[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)完成本阶段的选择器和菜单。所属层空间、来源有效性与输入范围沿[所属层规格](<2026-10-13-uilib-layer-input-spec.md>)，有限列表沿[交互集合](<2026-10-18-uilib-virtual-collection-spec.md>)，动作沿[共享命令](<2026-10-18-uilib-command-spec.md>)。

前端参考采用[React Aria Select](https://react-aria.adobe.com/Select.html)、[Menu](https://react-aria.adobe.com/Menu.html)的可操作案例及其[触发器实现](https://raw.githubusercontent.com/adobe/react-spectrum/main/packages/react-aria/src/menu/useMenuTrigger.ts)、[选择器实现](https://raw.githubusercontent.com/adobe/react-spectrum/main/packages/react-aria/src/select/useSelect.ts)；菜单Tab退出沿[APG Menu](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/#keyboardinteraction)。默认方向、字符导航、指针选择与Tab退出按这组参考执行，业务值仍受控。

## 1. 选择来源与动作来源

SceneSelect是非编辑单选选择器。业务提供有序Option(key,name,enabled)、当前键只读来源和选择意图；当前键可为null或不在来源中，触发按钮显示占位名称，不自动写回默认值。当前选中项变为禁用仍显示其名称，禁用仅阻止新的用户选择。触发器尾部显示展开箭头；弹出选项用尾部勾选标记表示业务当前值，标记不随预览焦点移动。确认选项时即时重读当前来源、键和可用条件，已选键不发布重复改变；业务拒绝后继续显示真实来源。

SceneMenu接受触发名称与有序Item(key,name,SceneCommand)，选项资格来自同一命令executable。确认后使用原SceneCommand.tryExecute，不复制菜单动作与快捷键动作。运行时变化的名称、命令资格和纯重排保留同键行；按键已退出来源时不激活新对象。两种控件均要求当前非空键唯一，重复键在调用行工厂前定位。

打开状态属于本次控件呈现，与业务选择分离；关闭不提交当前预览焦点。选项仅包含名称和标准动作，复杂行内编辑继续使用原集合。右键触发、可编辑组合框、搜索补全、嵌套子菜单及菜单复选项留给各自专题，不改变本阶段主键合同。

## 2. 弹出内容的来源、空间与有限行

触发按钮直属拥有一个INTERACTIVE所属层，打开时建立、关闭时结束其视图；显式modal使用原唯一范围进入及返回。弹出层使用默认来源下方锚定及页面限位，不把视觉层变成第二节点树。宽高按当前字号、内距和视口约束求解，正文是原虚拟集合，长度超过容量时使用原纵向滚动及滚动条；触发按钮仍服从普通Size。业务元数据可随来源增长，昂贵行树、度量与绘制围绕视口和合法导航目标。

打开选择器时按当前有效选中键准备并聚焦；缺失或不可用时取首个可用项。菜单从首个可执行项进入。初始目标通过原集合有限逻辑游标准备，不先聚焦临时首项再纠正；屏外当前选择也能按键准备，并在本次打开结算内显露到当前弹层视口；新起点游标准备到真实目标后显式发布原requestInputReveal，不改变普通模态初始“不追焦”或旧集合条件。原VirtualList公开create/focus及原逻辑起点条件保持，复合弹出内容仅增加同包起点游标。

弹出来源完全裁掉、隐藏、禁用、卸载或销毁时，本次打开状态结束；来源恢复不重新打开旧层，也不复活原焦点/按压/组字联系。若只是被另一合法模态覆盖，按原范围规则保留该层及合法恢复记录，不将覆盖误判为来源失效。

## 3. 输入、确认与关闭

触发按钮在主键按下时打开，并让原捕获在自己开启的所属模态内延续：拖入可用项后释放可确认该项，直接在触发器释放只保留打开状态；没有建立第二owner。synthetic完整激活、Enter和Space按各自标准时机打开；Down从首项方向打开，Up从末项方向打开，选择器有有效当前选择时仍优先该项。闭合选择器的Left/Right直接发布前后选项意图，当前键不在来源时两个方向均取首个可用项；当前键仍在来源但已禁用时，从其原位置分别寻找前后可用项；普通文字按名称前缀直接选择，不要求先打开。弹出后Up/Down按当前有序可用键移动，选择器到边缘保持，菜单到边缘循环；Home/End取首末，文字前缀跳到匹配项，连续同一字符循环同前缀项。悬停可用项改变实际焦点并使用指针焦点线索；弹出内方向/文字只预览，不写业务选择。每次导航目标经原行集合按键有限准备、实际资格核验与必要显露。按住方向沿原实际消费者有限续段，在本次弹出范围及合法当前项内继续；离开或关闭终止，重新打开不复活。

选项完整点击、Enter或Space确认当前真实项。选择器先结束弹出状态，再发布该键业务意图；菜单先结束弹出状态，再调用当前可执行命令。状态及动作失败保留原异常，旧事件不改作宿主继续，也不执行同批后续输入。空来源或全部不可用时可显示空结果，没有备用选中或自动执行；ESC仍可关闭。

ESC关闭当前弹出内容并消费本次退出；Tab/Shift+Tab关闭而不提交预览，并在同一次输入结算中从原触发位置继续到外层前后逻辑控件。设备中性逻辑导航与KEY入口均采用这个退出行为。当前范围根可通过默认不参与的SceneControl.navigateScope接收显式NEXT/PREVIOUS，初始/返回默认选焦不调用该口；因此无焦点的空结果也可关闭，合法模态返回不会被误认成Tab退出。显式Tab退出由原FocusRouter保存一次原范围/触发挂载/外层联系，关闭结算且原外层仍当前时沿同一路由继续；范围被其它动作替换或当前批次失败就丢弃该待执行意图，不改变当前焦点和正常模态恢复。确认、ESC、外部点击后的焦点返回沿原modal恢复记录；原触发已失效时不制造备用目标。

外部主键按下关闭弹出内容，本次物理段的UP不激活其下按钮。它沿原HitTester/PointerRouter：弹出层的正式pointerTarget只在其同批外盒之外、页面视口之内返回关闭目标；捕获后在DOWN结束打开状态。原物理按钮占位和失活owner继续吞尾，不向后台重投。外部synthetic activation也只关闭一次；非主键继续原占位规则。层内滚动条与选项仍按正式几何命中，不能把内部滚动误当外部关闭。

## 4. 真实消费与验收

在既有项目/通知工作流消费负责人或频率选择器，以及共享保存、重置或关闭命令的动作菜单。业务反馈展示选择和命令结果，至少一个动态禁用项；页面不添加全局鼠标或键盘监听。

| 场景 | 可观察结果 |
| --- | --- |
| 打开到有效/屏外当前键或首可用项 | 首目标正确，昂贵行有界，不临时聚焦别的项 |
| 方向/HomeEnd/按住方向 | 跳过禁用项、必要显露，预览焦点不改业务选择 |
| 点击/Enter/Space与外部拒绝 | 只有确认产生意图或同一命令动作，按钮名称反映真实来源 |
| ESC、Tab和外部主键关闭 | ESC/外部关闭返回合法原焦点；Tab一次继续相邻控件，旧repeat和UP不激活后台 |
| 源重排、删除、禁用及空来源 | 键和行身份正确，无迟到动作或默认写回 |
| 来源full clip/隐藏/卸载及重新出现 | 本次层与输入联系结束，不自动重新打开 |
| 有效外层被内模态覆盖 | 原范围隔离与恢复成立，覆盖不等同来源退出 |
| 命令/工厂失败及关闭 | 原错误可定位，所属视图释放，业务选择独立保留 |

稳定语义通过正式ScenePageSession与真实共享页面核对；弹层标记、可读性、限位、焦点线索及宿主回调通过实际可见运行验收。
