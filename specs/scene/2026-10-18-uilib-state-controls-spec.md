# 开关与单选组规格

状态：沿[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)交付标准状态控件，复用正式按钮、[命令](<2026-10-18-uilib-command-spec.md>)及唯一焦点。复选框既有三态和用途保持。

采用[React Aria Switch受控开关案例](https://react-aria.adobe.com/Switch.html)和[RadioGroup配送选项案例](https://react-aria.adobe.com/RadioGroup.html)的真实状态与change意图；单选组停靠与方向沿[APG Radio](https://www.w3.org/WAI/ARIA/apg/patterns/radio/)，无选择时反向进入末个可用项，Enter/Space按共享完整按压合同执行。

## 1. 状态与改变意图

SceneSwitch呈现一个布尔来源并发布切换后的布尔意图，业务决定是否写回。其名称、可用资格、当前状态、尺寸和主题是可追踪声明。合法完整点击、Enter按下及Space完整释放复用原按钮激活；按住Space期间离开、失活或取消就结束本段，返回不复活；每次动作即时读取当前来源，外部拒绝后不保存自有选中副本。禁用不发布改变，按原规则结束旧交互；背景、拇指和焦点线索使用同代正式几何与PaintCommand。

开关的外观为有明确两端状态的轨道及拇指，尺寸随当前主题字号/内距变化，显式Size覆盖保留普通布局含义。可以显示名称或只画开关并保留名称供提示/后续语义。它不创建内部额外焦点。设置页原接管文字开关消费该能力，原条件、动作和显式尺寸含义保持；开关不隐含保存配置。

## 2. 单选组与唯一选择来源

SceneRadioGroup接受有序选项声明、当前选中键来源及选择意图回调。选项包含非空稳定键、名称和可用来源，同组有效声明键重复时明确定位错误。当前选择可以为null或暂时不在当前选项中，组只呈现该事实，不自动写业务默认值；隐藏/删除或禁用当前项也不替用户重选。源顺序变化通过NodeBinding.repeat保留仍在的项身份，名称/可用状态变化不重建动作。

组拥有一个逻辑Tab入口：优先当前有效选中项，否则首个可用项。组内现有键盘焦点优先作为当前停靠点，Tab离开时进入下一个组外控件；有有效停靠/选中时反向进入同一项；两者都没有时，正向取首个可用项，反向取末个可用项。上下或左右按当前选项顺序循环，跳过不可用项，Home/End选首/末；方向移到目标时先请求唯一焦点，并发布该项选择意图，业务拒绝时焦点仍可用于查看。未挂载、失活或新的范围覆盖时不执行迟到改变。

普通点击、Enter及Space选择当前项；选择已选中键不发重复状态变化。选项内部不另嵌可聚焦内容，名称为普通标签；复杂行内编辑继续用原集合和选择合同。组不拦截焦点外的方向事件。组无可用项时没有Tab入口；空组和单项均不制造焦点循环通知或备用选中状态。

## 3. 同一输入与生命周期

组内方向是正式选项控件的编辑命令，优先于页级空间导航；Tab不被组当成选择动作。原KEY按压重复只延续首次获准的语义。单选组的方向先由组内行为消费，Core为这次实际消费者登记有限的SceneEditContinuation：只有原组挂载、原范围和当前合法组内项仍有效时才接续，沿同组当次焦点继续移动。焦点离组、组失活/卸载、范围结束或关闭会结束该按压续段，重新进入不能复活它；每次fresh按压重新登记。核心在首段执行前准备可选许可，只为实际消费方保留；唯一路由每次实际owner转换立即核验续段的当前目标，合批只读快照不替代这项离组事实。所属资源随段结束释放。普通文字编辑继续要求原焦点挂载，不取得这种跨选项权限，应用快捷键继续至多一次。模态、组字、失焦及Effect后范围核验沿共同输入管线。选择回调抛错时保留原异常，当前事件不执行后续宿主动作或同批文字；不把失败当未消费继续。续段资格扩展抛错会结束该许可；唯一路由完成已发生的焦点转换及必要通知后传播原始错误，其余许可仍得到核验。

实际焦点仍归SceneFocusRouter。组内停靠投影由原SceneFocusTraversal.begin提供单一逻辑入口：从组内开始返回END，从外部开始只返回当前有效组内焦点、有效选中项或首个可用项；实际可用选项仍可聚焦，不通过删除其focusable资格来模拟停靠。这个投影不拥有第二焦点；目标准备与焦点改变使用当前挂载句柄，关闭释放原观察和所属行呈现。业务选中状态不随卸载清除。

## 4. 真实消费与验收

设置或表单页面组合布尔开关和单选组，业务反馈即时显示当前选择、可用和拒绝状态。至少保留一个外部状态改变及一个禁用选项，不用组件私有缓存模拟业务状态。

| 场景 | 可观察结果 |
| --- | --- |
| 开关点击、Enter/Space及外部状态改变 | 状态/拇指同步，意图即时重读，拒绝不保留伪状态 |
| 显式尺寸/字号/主题变化 | 几何、命中和焦点线索同步，无内部额外停靠 |
| 单选组Tab进出、方向及Home/End | 一个Tab入口，跳过不可用项，选择与焦点职责分开 |
| 业务拒绝、当前项删除/禁用及空组 | 不自动写回默认值，当前合法焦点/停靠资格正确 |
| 动态重排、同批选择后输入、模态/失焦 | 原挂载及输入范围有效，旧尾部不触发后来目标 |
| 关闭/重挂及动作失败 | 所属观察释放，原错误传播，业务状态独立保留 |

稳定行为通过正式ScenePageSession验证；开关轨道、选中标记、可读性与键盘线索需由宿主实际画面核对。
