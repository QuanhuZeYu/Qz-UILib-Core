# 矢量路径、仿射呈现与形状裁剪

状态：沿[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)推进绘制表达，用于环形进度、径向菜单、旋转标记及形状视口。页面仍声明普通SceneNode、业务Signal与控件；Core发布共同几何和不可变PaintPlan，Platform负责已有有序GL回放，Minecraft复用对应正式产物。

前端用法采用[React Konva自定义形状](https://konvajs.org/docs/react/Custom_Shape.html)的局部直线/二次曲线与填充描边、[Path示例](https://konvajs.org/docs/shapes/Path.html)的可复用曲线数据及缩放、[Group形状裁剪](https://konvajs.org/docs/clipping/Clipping_Function.html)的多个子路径、[嵌套变换中的相对指针](https://konvajs.org/docs/sandbox/Relative_Pointer_Position.html)的当前绝对矩阵逆映射。矩阵组合与裁剪规则沿[Canvas transform](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/transform)、[clip](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/clip)、[路径用法](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Drawing_shapes)与[描边样式](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Applying_styles_and_colors)。采用参考的坐标和交互含义，实际实现继续UILib自有布局、路由、资源与批处理。

## 1. 路径与局部绘制

路径为不可变纯值，支持多个子路径、move/line、二次与三次Bézier、圆弧及close，可构造矩形、圆/椭圆与环形或扇形等组合。Builder后续更改不修改已发布路径。坐标以当前局部logical px表达；数据、颜色、尺寸或路径变化沿已有Signal/Computed失效，不把构造时的窗口、字号或缩放保存为固定环境。

填充默认NON_ZERO，可显式EVEN_ODD；多个子路径、凹形、自交及空洞按同一规则处理。填充会闭合开放子路径；描边只在显式close时闭合。描边宽度以路径中心线向两侧展开，端帽支持BUTT/ROUND/SQUARE，连接支持MITER/BEVEL/ROUND；默认BUTT、MITER与Canvas相同，尖角超过声明miterLimit时成为bevel。空路径不贡献图元；零长度子路径按所选端帽和真实几何处理。

正式矢量控件接收路径、填充/描边和局部视图尺寸声明，测量与最终分配仍由原布局承担。自然尺寸是声明的viewBox，居中描边可见外半参与实际几何和命中；显式clip仍按当前外盒裁剪。路径可直接进入PaintCommand，不要求页面维护GPU句柄、纹理、窗口或逐帧回调。矢量控件需要动作时沿原焦点、click/共享命令及Mount联系；命中用当前实际填充或描边几何，透明空洞不成为矩形按钮的替身。

## 2. 子树仿射呈现

页面可为普通节点声明可追踪仿射变换，提供平移、旋转、缩放、斜切、组合及明确原点的便利入口。默认单位矩阵保持现有入口、坐标和使用条件。变换在当前节点已分配的局部坐标系生效，并作用于其普通呈现后代；嵌套沿父到子的矩阵次序组合。原Node平移、滚动、弹性和布局动效保留其既有含义，不叠加第二位置来源。

仿射呈现改变当前画面位置和形状，不把缩放后的包络当作新的自然尺寸、换行宽度或兄弟占位。需要改变排版尺寸时继续已有Size与正式测量声明。变换自身和原点只使相应呈现事实失效，稳定帧复用结果，不为旋转重新创建节点、字段或业务草稿。

共同几何同时保留原局部分配与本批到页面坐标的映射，公开页面边界以当前实际呈现的保守包络表达。绘制、命中、悬停、光标定位、滚动、拖放、方向导航、所属层锚定及[语义快照](<2026-10-18-uilib-semantics-spec.md>)都消费这一批事实。精确形状和局部坐标判断使用对应映射，不仅用包络矩形命中。旧标准控件仍沿原控件局部的几何与坐标处理输入，框架在统一边界完成映射，不要求每个字段、滚动条或按钮重写旋转算法。正式几何的world读取保留页面坐标；asControl(node)把同一批事实读到该消费者原布局frame，按几何与消费者缓存身份。跨节点精确测试使用contains/visibleRegion，点跨frame使用mapX/mapY，不把其它节点投影后的AABB当作其实际轮廓。公开几何观察仍返回world事实；持续拖动保留world样本，在来源稳定父frame求布局位移，阈值沿页面像素。

反射和非均匀缩放正常参与组合。缩放到零等不可逆矩阵可用于呈现变化：该分支没有可逆的指针命中，当前失去坐标联系的捕获按原取消和吞尾规则结束；逻辑数据、显式可见性与键盘范围仍沿原声明。矩阵和路径只接受有限坐标，非法声明在原声明/准备路径暴露，不静默替换成单位矩阵。

## 3. 形状视口与共同裁剪

节点可声明局部形状裁剪，普通矩形clip与scrollable规则继续可用；形状裁剪同样作用于自身和普通后代。裁剪形状随本节点当前分配与变换定位；椭圆、圆角框或有明确viewBox的路径可随最终尺寸更新，页面不读回布局再写尺寸或路径。

嵌套裁剪取所有有效区域的交集，路径中的子区域按选定填充规则组合。世界包络只用于保守剔除，裁剪的洞、圆角及旋转边界由精确区域事实裁决。形状外不绘制，也不接收新的click/hover/wheel/drop命中；既有捕获移出形状仍沿原owner处理释放。裁剪变化使合法性按同一挂载/范围规则重验，不能借旧几何将UP投给后来对象。

[所属层](<2026-10-13-uilib-layer-input-spec.md>)继续从页面视口定位，逃离来源普通祖先的局部裁剪；锚定使用来源当前实际呈现边界。来源与页面/有效裁剪无真实可见交集时，本次层停止有效呈现。层内重新沿自己的变换和裁剪组合，不把已定位的页面坐标重复应用来源的矩阵。

## 4. 不可变计划与现有后端

每个绘制命令携带当批已解析的局部到页面映射、有效裁剪及路径/网格纯值，不持有SceneNode、Signal或绘制闭包。旧RECT/LINE/TEXT/IMAGE/VIDEO工厂默认单位状态，既有入口不增加新参数。新PATH及显式正式几何组合保留sceneGeometry纯值事实；矩阵归为单位值时有限caller裁剪仍作用于真实顶点。该事实不改变原坐标烘平移或原生图像直接委托条件。文字/图像的实际纹理采样、资源预算与可用分支沿原合同；变换和裁剪作用于真实顶点与采样坐标，不能将旋转图像或文字替换成其外接矩形。

通用路径展平、填充区域及精确裁剪采用共享的中性几何运算，绘制和命中复用同一准备结果。曲线精度以当前呈现像素误差控制，变换/尺寸变化后按原失效更新。网格和区域只保留当前计划或当前挂载需要的有限数据，不累积跨帧历史或创建屏外节点。

共享GL回放继续原有序批次、相邻材质合并、资源所属与恢复。裁剪后的多边形保留插值采样坐标，沿现有顶点提交表达；CPU区域计算和GPU提交分别负责中性几何与宿主资源状态。图片备用分支、overlay、Presence片段与世界文字回放仍保持原选择、顺序和同代映射，不能漏掉嵌套片段或重复变换。错误与资源结束沿原有边界传播和收尾。

## 5. 真实使用与验收

共享页面组合环形进度、扇形动作区域、可旋转标记与带普通按钮/字段的形状视口；控件参数可由现有状态改变。案例同时表达可见结果和真实业务动作，继续使用正式主题、字号和唯一输入管线。

| 场景 | 可观察结果 |
| --- | --- |
| 曲线、多子路径、凹形、自交与不同填充规则 | 几何覆盖和透明空洞正确，命中与实际填充一致 |
| 端帽、连接、尖角、半透明描边 | 实际轮廓正确，同一笔画的重叠部分不因拆图元重复变暗 |
| 嵌套平移/旋转/缩放/斜切及动态矩阵 | 内容与命中同步，原占位和草稿保留，旧位置没有幽灵目标 |
| 变换中的字段光标、滑杆、滚动与拖放 | 输入在当前局部坐标处理，原手势owner与范围合同成立 |
| 嵌套形状clip、洞、滚动和来源所属层 | 精确交集同时约束画面和新输入，来源锚定与范围隔离正确 |
| 字号/缩放/窗口/资源变化与静止 | 路径精度和局部分配更新，稳定结果复用，不做逐帧全量求解 |
| 文本、图像、视频及备用/overlay/Presence片段 | 正式有序回放不丢资源、分支或变换，旧入口仍可使用 |
| 关闭、不可逆矩阵及动作/准备失败 | 原捕获尾部不转投，所属资源释放，原错误可定位 |

中性几何和交互通过正式ScenePageSession及原自动化入口验收；像素输出由原软件图元消费者与GL绘制入口核对。用户桌面占用期间继续无窗口源码、构建和软件反馈，实际GPU/设备验收在所属宿主恢复运行时执行。
