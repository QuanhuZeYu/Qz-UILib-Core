# 交互树视图规格

状态：沿[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)推进树数据视图；有限呈现、独立状态和输入联系复用[交互集合](<2026-10-18-uilib-virtual-collection-spec.md>)，方向与编辑优先沿[方向导航](<2026-10-18-uilib-directional-navigation-spec.md>)。

前端案例采用[React Aria Tree](<https://react-aria.adobe.com/Tree.html>)及其[完整示例](<https://react-aria.adobe.com/Tree.md>)：树提供可聚焦主条目，包含字段的复杂行采用 `keyboardNavigationBehavior="tab"` 的条目内交互方式。主项展开、父子/上下移动、Home/End与名称前缀跳转对齐[WAI-ARIA APG Tree View键盘规则](<https://www.w3.org/WAI/ARIA/apg/patterns/treeview/>)；焦点与业务选择保持分离，主项动作继续调用业务动作。

## 1. 逻辑树与展开投影

业务提供条目来源、稳定键函数、父键函数和只读展开键集合。根条目的父键为null；来源可以先列出孩子再列出父项，同一父项内的兄弟顺序按来源中的相对顺序。Core据此生成展开后的深度优先逻辑行，再交原SceneVirtualList有限呈现。树的层级不通过SceneNode父子链储存，不为屏外条目建立节点。

每个非空键在整棵树中唯一，非null父键必须存在，循环引用使用可定位错误通道暴露。校验以逻辑条目和键关系完成，不调用行工厂或字体服务。行Entry提供当前值、键、父键、深度、是否有子项和当前展开状态，供标签、独立动作和业务选择呈现。源条目值变化与重新排序沿原稳定键更新，不把节点绑定给另一键。

展开集合仍归业务。Core发布Expansion(key,expanded)意图，调用方决定是否更新源集合；按钮和键盘使用同一即时核验动作。收到迟到意图时重读当前条目及其是否有子项，已经退出的键不影响后来对象。叶子没有展开动作；当条目以后取得子项时，按当时业务展开集合决定呈现。异步数据加载由来源发布，树不猜测尚未提供的孩子。

## 2. 行内容与交互

每个可见行包含可聚焦的树主条目、按深度缩进、一个标准展开标记和调用方行内容。普通标签或布局工厂不必补focusable，行wrapper提供主条目；已有可聚焦工厂根继续作为主目标。缩进由可追踪选项或当前字号派生，宽度不足时保持合法尺寸；行内文字换行、编辑、图标和独立按钮沿正式测量与共同几何。标记使用普通正式按钮/图形，无独立指针监听；标记不是额外Tab停靠点，点击不抢行内已有编辑焦点。

树主目标恰为当前焦点且不属于文字编辑目标（包括只读字段）时，原目标未消费的方向命令由树后置接续。Right在有子项而未展开时发布展开；已经展开时请求第一个可用直接子项；Left在当前项展开时发布折叠，否则请求最近可用父项。Up/Down按当前展开的深度优先顺序移动主项，边缘保持焦点；Home/End到首/末可用主项而不展开隐藏分支。提供逻辑textValue名称的create重载支持字符前缀跳转、快速多字符匹配和重复首字母循环；读取业务名称即可定位屏外主项，不为搜索构造全树视图。旧工厂重载继续可用，字段和独立控件自身的编辑始终优先。

树以原逻辑遍历提供一个Tab入口：进入主项后，Tab/Shift+Tab只遍历当前条目的独立动作和字段，再离开树，不依次停靠所有条目。主项间使用树方向键移动；原VirtualList单独使用时的Tab顺序保持。Enter/Space沿主项正式动作，已有按钮可以打开文件、显示详情或改变业务选择；仅由树提供的普通主项可用该动作切换分支展开。字段的光标、选区、组字与提交优先，树不抢当前编辑或内层独立动作。SceneControl.editFallback只接续原目标未消费的事件，不对新焦点重投；方向续段沿原唯一输入管线，仅许可本棵树的当前主项，离树或进入字段即结束。

可选disabledKeys是业务持有的可追踪禁用键集合。禁用项继续显示，不能聚焦、展开或激活；主项方向、首末、初始入口与名称匹配均在逻辑元数据中跳过它，不靠调用工厂探测资格。动态禁用当前项按原规则清焦，重新启用不恢复旧焦点；旧重载默认无禁用键。工厂内独立动作的可用条件继续属于该动作，不以它代替整个TreeItem资格。

## 3. 焦点、选择与折叠

树焦点仍由唯一SceneFocusRouter维护，选择可用SceneSelection独立表达。展开/折叠不默认选择节点，不清除业务草稿或选择；按当前展开投影的范围选择由业务显式采用。真实数据删除由业务决定是否限制独立选择/草稿。

树键盘产生的主项移动只请求原行集合按稳定键准备并聚焦，最后资格与必要显露由唯一路由核验。目标不存在或已失活时结束该次请求，不激活替代对象；纯内容条目使用控件提供的主目标。折叠隐藏的后代结束当前视图及旧挂载输入联系；外部展开来源使当前焦点行退出时，按原失活规则清焦，不擅自改选祖先。再次展开可恢复独立草稿，原挂载不会复活。

公开node、可见逻辑行和原行集合/视口，页面可以组合现有滚动条和工具栏。按键显露/聚焦只针对当前投影中的键；不因focus/reveal隐式展开祖先或写业务展开状态。

## 4. 资源与验收

逻辑索引、父子映射和展开投影可以随源条目数增长；昂贵行工厂、控件树、度量和绘制围绕视口、有限预取及合法焦点/捕获例外。展开改变投影只构造新准备行，普通静止不重新生成条目树。卸载/重挂及关闭沿原Owner和节点资源规则，不把业务状态生命周期绑到离屏行。

真实消费在既有场景工作台提供资源/项目浏览器：目录可展开、主项动作发布实际打开反馈，行内重命名字段保留业务草稿；宽度、字号、重新排序和外部展开来源可以动态改变。

| 场景 | 可观察结果 |
| --- | --- |
| 根/多层/先孩子后父的来源 | 层级、兄弟顺序和展开投影正确，无全量节点树 |
| 展开、折叠及外部展开集合变化 | 行键连续、无隐式选择，隐藏后代旧尾部不激活其他对象 |
| 主目标四方向、Home/End与名称前缀 | 展开/父子/可见DFS首末及屏外名称定位正确，不全量建行、不隐含选择 |
| 普通标签与复杂条目Tab进出 | 自动具备主项，Tab进入当前条目字段/动作后离树，字段消费方向与文字 |
| 动态禁用、禁用首末及名称匹配 | 禁用项可读但不参与导航，当前项失活清焦，重新启用不复活联系 |
| 行内编辑及独立动作 | 文本光标与IME不被树抢走，按钮保留本来动作 |
| 多层千行、跨屏及回滚 | 工厂有界，必要目标同批准备、显露，草稿在业务保留 |
| 折叠焦点后代并再次展开 | 旧挂载结束、不自动选祖先，独立状态恢复到新视图 |
| 重复键、缺父、循环及工厂失败 | 原错误可定位，已取得所属资源清理 |

稳定逻辑通过正式ScenePageSession和源数据变化验证；实际缩进、标记、可读性和输入回调通过宿主可见画面核对。
