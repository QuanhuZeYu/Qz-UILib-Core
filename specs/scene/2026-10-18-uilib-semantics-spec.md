# 无障碍语义与宿主读取规格

状态：沿[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)交付角色、名称关系、值/状态、动作与变更。Core输出与场景同代的中性语义，Platform/Minecraft宿主消费快照并递交语义请求，设备与原生无障碍桥仍归宿主。

前端采用[React Aria TextField名称/提示/受控值示例](https://react-aria.adobe.com/TextField.html)、[Switch状态与只读用法](https://react-aria.adobe.com/Switch.html)、[Tabs角色与面板停靠](https://react-aria.adobe.com/Tabs.html)和[FocusScope返回示例](https://react-aria.adobe.com/FocusScope.html)：标签与值分别表达、状态来自业务来源、禁用与只读含义不同、焦点使用共同范围。语义描述是这些控件可读事实的中性投影，页面作者补名称或标签关系即可。

## 1. 宿主取得的事实

正式ScenePresentation增加不可变语义快照。宿主可读取语义节点的身份、逻辑父子、角色、完整名称/描述、当前值、可用/只读/选中/勾选/展开状态、实际焦点、可聚焦性、同批盒/裁剪与是否屏外，以及当前可执行动作。名称取完整来源文本而不是省略后的画面字符串；字段的内容是value，标签或显式名称才是name。

每次真实挂载取得新的不透明语义ID，节点在原挂载内重排、滚动、改值仍保持ID；卸载/重挂或拥有式销毁后重建取得新ID。旧快照是值，不暴露可修改SceneNode、业务Signal或直接动作闭包，不因宿主保留旧快照而维持退出节点或整个runtime。宿主发回旧ID时只能失败，不能找到同键新对象。业务键、节点UUID与挂载身份沿原合同区分。

快照维护逻辑层级，普通纯布局节点可透传语义孩子，显式GROUP保留分组；被动装饰可排除。所属层仍沿来源的逻辑关系表达，输出标明当前有效modal范围及焦点；模态覆盖的后台可以保留阅读事实但不提供可执行动作。visible=false、退出所属层或已销毁的视图不出现在当前快照。当前挂载且因滚动部分/完全裁剪的合法节点保留屏外事实；不为未挂载屏外条目创建语义控件树。

只读和禁用保留其名称、值及阅读状态。当前页面有内层modal时，不把后台enabled来源改写成false；单独表达当前范围是否允许交互。离屏焦点保留实际focus事实与屏外状态，不为无障碍读取消耗输入或抢焦。

## 2. 声明、内建控件与标签关系

SceneControl提供默认无语义的只读描述端口，NodeBinding.semantics提供可追踪局部声明/覆盖；旧控件和页面不因此增加名称或状态前提。显式声明可以补name、description、role、labelledBy、describedBy及值，但不修改业务来源。只有真实存在的语义字段才输出，未知值保留为空，不通过字符串猜角色或选择状态。

正式按钮、图标按钮、标签、复选框、Switch、Radio、文本字段/多行字段、滑杆、滚动条、虚拟集合、数据表、树、Tabs、选择器及菜单提供内建角色与真实状态；复合控件使用所属容器、项与内容的语义关系，不把内部装饰额外朗读。复选三态明确checked/mixed；树项有层级、展开和子项事实；集合/表格给出逻辑条目总数、当前位置及列信息，行视图仍有限。

标签关系引用当前同页语义对象，发布时解析其实际挂载ID；关系目标失活、退出或重建会同步移除/更新，旧ID不复活。关系内容变化使依赖名称/说明失效。没有显式name时，labelledBy按声明顺序组合完整标签文字；字段placeholder作为提示说明，不冒充实际值或永久标签。页面可在现有标签旁声明关联，无需包装新输入控件。

## 3. 动作沿原输入序列核验

宿主通过ScenePageSession.semantic(request)把目标ID、标准动作及必要参数加入原有序输入批次。每次动作前沿原prepare结算声明、几何和范围；取当前挂载及当次语义资格，不直接调用旧快照闭包。旧ID、已禁用、非当前交互范围、不支持或已退出的动作返回拒绝，不向新焦点或宿主默认动作重新分发。

FOCUS使用唯一路由必要显露。ACTIVATE继续当前节点原正式激活/共享命令，不伪造鼠标DOWN/UP。SET_TEXT是对解析出的当前字段整段原子替换，沿该字段原编辑控制器更新独立草稿、选区和一个可撤销步骤，不通过全局dispatchEdit投给其它焦点，也不用reset清除历史或改业务基线；SUBMIT沿原提交策略，值更新和业务接受仍分开。INCREMENT/DECREMENT/SET_VALUE沿滑杆或滚动条的既有量化、预览/最终提交合同；EXPAND/COLLAPSE/SELECT继续所属树、Tabs、Radio或选择器的现有动作/改变意图，不保存语义选中副本。

semantic(request,completion)递交原队列，结果在该事件handler和Effect成功结算后异步报告已处理或资格拒绝；入队不代表执行成功，业务提交是否接受仍看原业务状态。失败以同一原异常结束请求并沿原批次失败通道传播，关闭或失败丢弃的未执行请求也结束，不保留悬挂结果或新增请求历史。单次请求只有当前目标获得动作；动作先切焦或打开modal后，同批后续请求按新事实处理。SET_TEXT和SUBMIT作用于当前仍有有效IME联系的字段时（包括UPDATE(active=false)只结束预编辑呈现的情况），或目标字段旧无来源入口仍composing时，返回拒绝并保持其草稿与preedit；既有明确取消结束联系后可执行。FOCUS和ACTIVATE按目标原有资格执行，真实焦点或范围改变由原联系重验终止旧组字，不增加全页组字锁。该区分沿[React Aria FocusManager](https://raw.githubusercontent.com/adobe/react-spectrum/main/packages/react-aria/src/focus/FocusScope.tsx)的显式焦点用法：键盘组字事件保护与程序化目标动作分别处理。回调或描述求值失败保留原异常并走当前批次失败通道，剩余输入不继续；不把失败当拒绝或宿主继续。

## 4. 更新、观察与有界资源

语义描述及标签关系使用当前Signal/Computed和挂载Owner观察，变化只使所属语义失效，不为纯名称/状态更新触发全页重测或重新创建控件。共同几何、焦点、范围或生命周期变化后发布新快照；静止帧复用已有不可变结果。变更列表按语义ID区分加入、更新与移除，宿主可用当前快照恢复完整事实，不需要重放历史才能理解现状。

SceneHost提供默认无操作的语义发布回调，旧宿主无需实现。新增快照与默认端口保留现有ScenePresentation构造和ScenePageSession入口；宿主不消费语义时，原绘制、键鼠和业务合同保持。关闭释放观察与ID索引，宿主收到空结果/移除事实，旧ID请求失效；不持有无界历史事件或全部逻辑条目的节点树。

## 5. 真实消费与验收

正式设置/通知/项目页面用标签关联和控件内建语义表达可读表单；Platform与Minecraft的无窗口宿主读取实际快照并经页面会话触发动作。共享开发观察页面可以展示当前角色、名称、值、状态和焦点，属于后续统一检查入口的消费，不在Core实现OS服务。

| 场景 | 可观察结果 |
| --- | --- |
| 按钮、字段、状态控件与动态标签 | 完整名称和实际值状态正确，字段内容与标签分开 |
| 只读/禁用、模态覆盖及屏外焦点 | 阅读事实保留，动作资格与唯一范围/焦点一致 |
| 语义动作后同批新动作或文字 | 原共享命令/草稿/实际新范围被使用，没有第二输入权威 |
| 标签关系更新、重排、卸载重挂 | 关系和语义ID随当前挂载更新，旧快照不变、旧动作拒绝 |
| 千行集合/数据表/树展开 | 数量/位置正确，语义树与昂贵行同样有限 |
| 静止、状态变化与关闭 | 静止复用，局部变更不触发重测，移除发布且观察释放 |
| 动作或描述失败 | 原错误保留，当前批次停止，必要焦点/物理联系收尾完成 |

中性语义与动作由正式ScenePageSession验证；宿主输出及后续原生桥的实际设备行为在各自所属运行入口验收。
