# UILib 交互虚拟集合规格

状态：依据用户 2026-10-18 认可的[成熟度路线](<../proposals/2026-10-18-uilib-maturity-roadmap.md>)形成的首阶段实施合同。

## 1. 用途与职责

页面提供有序数据、集合内稳定业务键和真实行控件声明；Core 按视口需要实例化有限行视图，协调可变行高、滚动范围、输入、导航及资源释放。适用于长邮件、任务、日志和物品条目，行内可组合文本、图片、复选、按钮及独立编辑状态，不把交互行限制成单一动作。

本模块沿[核心职责](<../2026-10-07-uilib-core-contract-design.md>)、[动态结构](<uilib-dynamic-structure-spec.md>)、[编辑](<2026-10-07-uilib-editing-spec.md>)及[滚动](<2026-10-16-uilib-scroll-area-spec.md>)合同接入同一场景树、生命周期、共同几何和唯一路由器。普通 repeat、折叠、滚动和既有控件保持其原有含义。

| 责任主体 | 决定与执行 |
| --- | --- |
| 业务/页面 | 数据顺序、稳定键、行声明、独立草稿及选择集；过滤/删除后的业务状态去留和提交策略 |
| 集合控件 | 有限行视图、当前数据投影、行高度索引、估算与校正、逻辑导航目标及显露意图 |
| 场景运行时 | 声明结算、唯一挂载/焦点/capture、同批几何、绘制与释放；在后续输入前完成必要准备 |
| 布局与字体 | 在本次真实约束及资源条件下测量已实例化行，产生共同排列事实 |
| 宿主 | 实际空间、资源代际、正式输入和 PaintPlan 回放，不建立平台专属集合控件 |

## 2. 条目与行视图

**业务键标识持续条目，节点 UUID 标识实际行视图，挂载代际标识当前输入联系。** 同一集合的持续键更新数据或重排时，当前保留的行视图延续身份并消费当前数据；集合内重复键应定位报错。不同集合的相同键不自动建立移动或共享关系。

整行是否参与内容与导航，由工厂之外的逻辑数据投影表达。页面可以用既有 Computed 从完整数据和可追踪的条目资格派生展示序列；全部条目暂不参与时，该轻量投影仍观察资格来源，恢复后发布当前条目，不需要构造行节点。行视图内的显隐、子树折叠及固定/最小尺寸继续遵守普通布局规则；当前隐藏行不贡献高度或间距。行视图结束时其绑定随挂载结束，后续逻辑资格变化由数据投影唤醒新的视图，而非保留已销毁节点的任意绑定闭包。

未进入准备范围的条目保留数据与有限度量元数据，不预先构造行节点或建立行内控件挂载绑定。准备范围包括当前有效视口、有限预取带、明确导航目标，以及持有有效焦点或指针手势的行。预取只服务相邻滚动，不能逐渐扩大成全量驻留。

普通离屏且不再参与上述联系的行视图可以结束；以后返回可以创建新 UUID 和挂载。离屏视图结束不提交、清除或销毁业务持有的独立草稿、选择集或服务。仍持有合法焦点/组字、被覆盖范围的合法恢复记录或手势的行在当前集合保留为有限例外，用户滚动不因此被拉回，也不产生失焦提交。联系真正失效后按既有路由结束，随后释放行视图。

真实数据删除或换键结束该条目的现有行视图及输入联系；旧 DOWN/UP、组字来源及迟到回调不得激活后来占据位置的对象。同键在退出真实生效后重新加入是新条目。行视图不在不同业务键间改绑复用，避免把旧草稿、焦点或按压转交另一对象。

卸载释放挂载绑定及宿主联系，重新挂载按当前数据和资源准备；永久销毁结束所属行视图、索引和观察。业务共享状态不随集合销毁。

## 3. 布局、行高与滚动

集合默认填充分配到的有限视口，并提供纵向内容及标准滚动条。行宽遵守其尺寸声明和集合正文宽度；固定高度及自然换行均沿正式子测量求值，内距和行间距按声明计算。业务不提供可见行范围、占位节点或最终行位置。

**当前可见行使用实际测量；尚未取得当前条件度量的行使用明确估算。** 总范围允许随取得真实行高而校正，不声称未测量内容具有精确总高。估算值由当前主题/声明提供初值，不能将旧宽度、字号、字体或资源条件下的度量当作当前精确事实。

已测量高度以条目身份、当前内容条件、宽度和资源环境为有效性依据；重新可见时核对并测量当前内容。局部内容变化只结束实际受影响的高度事实；整份数据发布允许必要的键匹配与索引维护。全局宽度/资源变化结束依赖旧条件的度量，当前视口及时重测，其他行按需取得事实。

布局产出每个准备行的真实区域及共同裁剪，所有可见内容、命中、所属浮层和滚动条使用同批事实。高度索引可缓存纯度量结果，不保存当批子测量入口，也不在测量/绘制中写业务状态或改节点归属。

仅因估算校正或宽度/资源重测改变行高时，保留此前视口首个可见业务键及行内像素距离。锚点行仍贡献内容时，先把旧行内距离限制到该行当前有效内部位置，再限制到集合总合法范围；锚点行变为零高或不再贡献内容时，保留原像素位置并限制总范围。数据增删/重排保留已有像素位置并限制到新范围，不默认加入数据排序锚定或追焦。显式导航以其目标为准；明确跳到末尾时在本次校正中完成末尾显露，后续追加数据不自动追尾。

正常滚轮、独立滚动条、像素移动和嵌套显露使用同一个位置所有者。范围缩小时限制偏移；反向滚动立即响应。静止无变化时不重建视图或重新求解行。

## 4. 按需导航与行内操作

**逻辑声明顺序包括尚未实例化的条目。** Tab/Shift+Tab 在有效输入范围内按数据行顺序及行内控件声明顺序前进/后退。集合边界衔接前后普通控件，不增加独立的 Tab 循环或把集合强制变成单一焦点停靠点。单项、空集合和范围循环沿核心规则。

导航到未实例化条目时，框架依序发布目标准备意图、实例化该行、取得其当前可聚焦目标和共同几何，再由唯一焦点路由完成聚焦与最小必要显露。跳过当前隐藏/禁用且不具备合法目标的内容，不能把屏外条目直接从导航流程中删去。行内没有目标时按同方向寻找后续条目；按需搜索服务本次导航或核心规定的范围进入/返回选择，不预先实例化全列表。

页面/模态进入以及返回后的默认选择也使用完整逻辑顺序。首屏行没有合法目标、屏外后续行存在合法目标时，唯一路由可以准备该屏外行作为逻辑首目标，不能直接越过集合选择页脚控件。该选择保留初始/返回不显露的既有规则：当前滚动位置不改变，被选行作为有限焦点例外保留；后续主动导航才请求显露。显式初始/恢复目标与合法保存焦点仍按核心既有优先级核验。

集合提供按稳定业务键显露条目和请求行内首个合法焦点的正式能力。显露本身不激活或提交，焦点仍由唯一路由核验。按键、指针、文本与显露的顺序由既有帧管线协调，前一导航完成后才把后续文字交给实际目标。数据删除、输入范围结束或集合卸载使未完成意图失效，不转投无关条目。

普通鼠标操作和行内复选/按钮/编辑使用正式控件，不复制命中或编辑管线。按压行或编辑行可在视口外有限保留；被裁剪部分不接受新的指针命中。列表外层及所属模态的范围限制继续有效。

## 5. 共享选择基础

选择集、活动项和范围锚点是独立逻辑状态，使用稳定业务键，不使用行节点引用。共享策略表达替换选择、切换选择、按当前有序键范围选择及显式限制到一组保留键；业务持有结果并决定过滤后的去留。控件只发布选择意图或展示声明结果，不默认推断全选范围或业务提交。

选择状态不随离屏视图释放而丢失；重排后的范围选择按当前逻辑顺序求值。焦点与选择分别维护，Tab 到达或用户滚动不擅自改变业务选择。物理组合键映射归命令/宿主输入专题，本阶段通过正式业务意图及现有行内控件消费同一策略。

## 6. 实现与资源边界

公开能力复用 Signal、Owner、SceneNode、NodeBinding、正式子测量、SceneScrollViewport、唯一焦点/指针路由和 PaintPlan。集合在呈现准备中接收本批视口/几何事实，发布后续声明；结构变化在受控结算中生效，页面不手动 flush/layout。

元数据和高度索引规模可随逻辑条目数增长；行工厂、挂载绑定、昂贵度量与绘制围绕准备范围工作。当前键集合退出时释放对应索引，行视图有界保留，卸载/关闭终止所属观察。数据改变时允许必要的索引重建，不把它与稳定滚动的行工作混为一谈。

无效键、非法尺寸、构造或扩展回调失败沿既有可定位错误通道暴露并完成必要所属清理；不添加自动重试、旧视图恢复、业务任务取消或失败回滚。

## 7. 可观察验收

复用统一 TestApplication、正式 ScenePageSession、真实行控件、正式输入与软件/实际宿主回放。期望取自业务数据和输入，不复制布局算法生成答案。

| 场景 | 可观察结果 |
| --- | --- |
| 长集合初次进入与静止 | 显示当前行，未访问行不调用行工厂；静止不重复建立绑定或测量 |
| 同视口下增大逻辑条目数 | 元数据/初始索引成本单列；稳定准备行及昂贵行工作保持围绕可见内容 |
| 混合变高行、换行、图片及局部内容更新 | 可见内容、真实行高、邻行位置和命中一致，无固定行高替代 |
| 连续滚动、拖条、到达末尾后反向滚动 | 当前行与业务对象一致，末尾可达，反向立即生效 |
| 普通行离屏并返回 | 使用当前数据与资源，独立草稿/选择保持，旧视图不会接收更新 |
| 编辑或按压期间滚动离屏 | 当前有效行有限保留，输入继续属于原目标，不追焦、不自动提交 |
| 删除当前行并在原位置放入另一键，再递交尾部 | 新对象不被旧按压或组字激活；后续新操作有效 |
| Tab/反向Tab跨越未实例化条目及前后普通控件 | 所有合法行内动作按逻辑顺序可达，屏外目标被实例化并显露，范围正确循环 |
| 行无合法焦点、禁用行、嵌套模态 | 跳过无效目标，只在当前范围导航，不使后台获得输入 |
| 导航与后续文本处于同批 | 文本进入完成导航后的正式编辑目标，不落到旧行 |
| 字号/字体/语言资料/主题/窗口变化 | 当前视口重测，行高校正保持约定锚点，返回的行使用当前条件 |
| 替换/切换/范围选择和数据重排 | 选择基于当前键与逻辑顺序，焦点和选择不混为一份状态 |
| 卸载重挂、页面结束及共享状态继续变化 | 无旧输入/观察残留，所属资源结束，独立状态和服务继续可用 |

性能负载、原始样本与同宿主收益遵循[大列表目标](<../proposals/2026-10-14-uilib-large-list-performance-spec.md>)及[性能压测](<../verification/2026-10-14-uilib-performance-testing-spec.md>)；保留原内容、规模及正式动作，对比首次进入、稳定滚动、局部更新、重排和释放。工作量降低和实际时间收益分别报告。
