# Scene HUD 放置与编辑

业务提供 HUD 内容、锚点、逻辑偏移和缩放，Core 以正式 SceneControl 排列内容；宿主提供视口与有效 GUI Scale，Core 不依赖游戏类型。位置、缩放和裁剪沿同一正式几何用于绘制及编辑命中；尺寸、字体、主题和视口变化后重新约束到可见空间，不读旧绘制计划补偿布局。

正常呈现不附加交互。显式编辑复用 SceneDraggable 的捕获、键盘、取消与放下意图，提供网格吸附；正常放下更新所属位置草稿，ESC、失焦或卸载取消不提交。缩放与默认恢复由业务修改同一位置值，Core 不持久化、不决定业务保存。

锚点按可用空间与内容实际尺寸计算，逻辑偏移随 GUI Scale 转换；过大内容按实际空间约束可见范围，不溢出产生另套命中。无平台正式会话数值/输入场景验证锚定、约束、拖动取消与动态变化；GPU 和游戏兼容由所属宿主取证。
