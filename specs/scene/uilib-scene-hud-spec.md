# Scene HUD 放置与编辑

业务提供 HUD 内容、锚点、framebuffer 像素偏移和显式内容缩放，Core 以正式 SceneControl 排列内容。HUD 坐标、尺寸、裁剪和命中统一使用 UILib framebuffer 像素；宿主 GUI Scale 不进入 Core，也不改变 HUD 尺寸、文字大小、偏移或吸附网格。尺寸、字体、主题和视口变化后重新约束到可见空间，不读旧绘制计划补偿布局。默认 CLIP 保留显式缩放并裁剪过大内容；可显式选择 CONTAIN，在所请求缩放下超出画布时保留真实自然排版，沿正式子树变换等比缩小至完整可见。CONTAIN 的有效缩放不超过用户请求值，不回写位置或缩放草稿，恢复空间后恢复请求缩放。

正常呈现不附加交互。显式编辑复用 SceneDraggable 的捕获、键盘、取消与放下意图，网格步长使用 Scene 像素；正常放下更新所属位置草稿，ESC、失焦或卸载取消不提交。内容缩放与默认恢复由业务修改同一位置值，Core 不持久化、不决定业务保存。

锚点按可用空间与内容实际尺寸计算，偏移保持像素语义；过大内容按实际空间约束可见范围，不溢出产生另套命中。没有有效可见位移的放下不改写位置草稿；有位移时优先保留原始小数偏移；若数值精度边界不能同时保持预览落点，则以该像素的精确偏移保持几何一致。若放下前的起点已被边界限位，则以当批已呈现的合法盒为拖动基准，避免放下跳回。无平台正式会话数值/输入场景验证锚定、约束、拖动取消、草稿精度与动态变化；GPU 和游戏兼容由所属宿主取证。
