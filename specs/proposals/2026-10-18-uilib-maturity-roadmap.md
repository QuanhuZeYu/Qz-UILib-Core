# UILib 通用桌面与游戏 UI 成熟度路线

状态：用户于 2026-10-18 认可成熟度判断、推进方向及长程实施；各阶段在所属模块规格明确行为后实施。

## 用途与目标

面向桌面应用、游戏菜单/HUD和工具面板，使页面作者通过逻辑数据、状态和正式控件组合复杂界面，复用共同输入、布局、呈现及资源生命周期。路线承接[核心职责](<../2026-10-07-uilib-core-contract-design.md>)，保留现有入口、数据含义及使用条件；新增能力的前提仅约束新用法。

Core 维护中性合同与共同逻辑；Platform 提供设备、原生输入、字体/媒体实现及 GPU 回放；Minecraft 负责游戏接入。新增能力继续使用 scene、Signal/Computed、Owner、共同几何和不可变 PaintPlan。

## 推进顺序与可用结果

| 阶段 | 交付能力 | 验收所需的可观察结果 |
| --- | --- | --- |
| 基础维护 | 字体换代失败时的必要清理 | 单项关闭失败仍尝试其余所属关闭并结束旧引用，保留原始错误；正常重载继续更新当前页面 |
| 交互集合 | 可交互虚拟集合及共享选择/导航基础 | 可变行高、行内动作和编辑能组合使用；屏外条目可经正式导航到达；滚出返回、删除和重排保持正确业务身份；昂贵工作围绕可见内容与实际变化发生 |
| 命令与导航 | 页面/范围级命令、快捷键及方向导航 | 按钮、菜单和快捷键触发同一动作并共享可执行状态；编辑与模态范围正确消费输入；二维控件按方向到达合理目标并必要显露 |
| 数据视图与复合控件 | 数据表/树、Tabs、选项组、Switch、选择器和菜单 | 稳定行键、列操作、树展开、选择与行内动作遵守同一集合合同；多页面复用统一焦点、开关、ESC及返回行为 |
| 无障碍语义 | 角色、标签关系、值/状态、语义动作和变更 | 宿主可读取控件名称、只读/禁用/选择状态及可执行动作；动态内容、有效范围和生命周期变化同步反映在语义输出 |
| 绘制表达 | 通用矢量路径、仿射变换、形状裁剪 | 环形进度、径向菜单、旋转标记及形状视口通过正式绘制合同表达；呈现、裁剪与命中共享事实；各后端保持有序回放 |
| 尺寸与密度 | 可追踪的控件尺寸角色及密度主题 | 切换紧凑/宽松密度后字号、内距、圆角和图标间距按角色更新，显式局部覆盖保持其声明含义 |
| 开发观察与业务接入 | 统一场景检查入口及真实调用方打磨 | 页面作者能定位布局盒、裁剪、焦点/捕获与失效来源；实际业务通过正式依赖消费新能力，重复组合回到所属公共合同 |

首个主要增量选择交互集合，它同时检验节点身份、独立编辑状态、焦点、滚动、动态布局和释放，并为后续数据视图及选择器提供基础。命令导航与集合导航共用唯一路由，不建立第二焦点系统。

## 首阶段范围

在[虚拟集合专题](<2026-10-14-uilib-virtual-list-spec.md>)和[大列表性能目标](<2026-10-14-uilib-large-list-performance-spec.md>)基础上，先确定逻辑条目、业务键、节点视图和挂载代际的区别。业务持有数据与独立草稿；Core 维护有限视图、度量事实、滚动范围及导航可达性。离屏不自动提交或丢弃独立草稿，真实删除按业务数据与节点生命周期结束。

首阶段以既有真实列表声明验证可变行高、复选/独立动作和编辑组合；覆盖屏外导航、往返滚动、删除重排、旧手势尾部、字号/语言/字体/窗口变化。导航、离屏焦点、行高估算校正和锚定的具体行为归所属集合规格维护，不由实现偶然行为定义。

优化保留原负载的内容、规模和动作序列，复用[性能压测](<../verification/2026-10-14-uilib-performance-testing-spec.md>)比较工作量和同宿主耗时。首次进入、首次访问新区域、全局资源变化及结束释放分别观测；稳定帧收益不能靠删掉行内动作、图片或缩短内容取得。

## 阶段交付方式

每个阶段形成有限的模块合同、公开使用入口和可运行消费者，补充能防住真实回归或替代实机验证的场景，运行受影响组合及所属仓完整 build 后本地提交。普通技术选择由实现者负责，根据实际反馈修正；正式规格维护共同合同，局部实现意图写在源码旁。

稳定逻辑采用现有统一测试应用；字体、GPU、原生设备和宿主行为通过对应实际运行入口取证。Core 注入输入只证明中性语义，不替代原生输入法及候选窗口验收。操作系统窗口、手柄设备、原生输入法桥和 GL 实现保持 Platform 归属。

右键菜单需要明确扩展既有非主键输入合同；多窗口/停靠工作台、高级组字分节、触控与复数/select消息按具体应用需求进入后续专题。本路线不改变版本、发布和远端操作约定。

实际进度、负责人、实施步骤和原始验证记录留在忽略的任务记录中，完成后清理；本文件维护阶段目标与依赖。
