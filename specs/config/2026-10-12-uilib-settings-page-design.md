# UILib 设置页面规格

共享设置页编辑 `font.candidates`、`ui.theme` 及 MC 宿主的 `mc.replaceVanillaFont`，共同持有一份跨分类草稿。配置发布、校验和 YAML 注释归[配置规格](<2026-10-11-uilib-config-spec.md>)；字体、宿主资源和焦点沿所属能力，不另建状态、输入或资源权威。

参照 [Shadcn Admin](https://shadcn-admin.netlify.app/settings) 的文档式工作台：左侧分类、居中限宽正文、宽屏非交互更改侧注；中屏隐藏侧注，窄屏以正式 SceneSelect 切分类。页头与底栏按真实内容测量，正文只占剩余空间并正式滚动；低窗可省辅助说明，不承诺固定可见行数。主题、字号、密度和视口动态生效。使用统一无衬线界面字体、中性灰、细分隔线及声明式弹性动效；字段不逐个套卡片。动效服从[正式策略](<../scene/2026-10-17-uilib-motion-spec.md>)，退场立即结束输入，快速重开沿当前呈现续接。

外观依次展示主题选择、字体摘要及管理入口、当前生效文字样本。顶部快捷切换与主题选项修改同一草稿，只在设置页预览；应用后全局发布，保存后持久化。样本可编辑和重置，使用实际生效 `default` 来源，不写配置；生效来源为空时不挂样本编辑器，明确说明不可用，不用界面字体冒充。

字体编辑器采用同窗列表与添加子视图。每个来源使用独立圆角卡片，卡片间留空隙，按真实顺序展示序号、名称、类型、标识或路径、把手及上移/下移/移除；长表内部滚动，不承诺虚拟排序。重复声明沿独立身份复用正式 SceneSortable；正常 drop 只发布一次草稿移动，ESC、失焦取消不改顺序，反馈、回落及边缘滚动沿通用合同。恢复默认、添加、排序和移除只改草稿，“完成字体编辑”只关窗口。空列表合法，仍可添加、应用和保存。

添加使用同组单选切换实际内置来源与本地文件；内置项沿正式 SceneSelect，路径可输入或由 UILib SceneFilePicker 回填，选择不自动添加。无内置项时直接使用文件模式。字段错误保留输入；添加成功、返回或 ESC 回列表，再次 ESC 关管理。选择器作为所属上层模态，ESC 优先关选择器并保留添加输入。初始与返回焦点沿[编辑](<../scene/2026-10-07-uilib-editing-spec.md>)和[核心范围合同](<../2026-10-07-uilib-core-contract-design.md#6-输入范围宿主与焦点>)，不依赖控件内部子序。

MC 宿主提供“接管原版文字绘制”草稿开关，应用后由所属接入发布；非 MC 宿主不提供可修改的游戏开关。配置文件页只读展示真实路径、YAML 格式及当前生效摘要，提供显式重载；页面不解析 YAML、不监视磁盘、不隐式重试。

| 操作 | 合同 |
| --- | --- |
| 应用全部更改 | 校验并发布全部所属草稿值，更新资源，不写文件 |
| 保存到文件 | 仅保存生效值；有未应用草稿时禁用，无变化时禁用 |
| 放弃编辑 | 草稿恢复到生效值，不撤销已应用但未保存的变化 |
| 恢复默认 | 对应模块默认值放入草稿，随后显式应用、保存 |
| 从文件重新加载 | 有草稿或未保存值先确认；成功替换生效值、保存基线及草稿，即使声明相同也刷新资源 |
| 返回或关闭 | 有草稿或未保存值先确认；不保存离开丢弃未应用草稿，已应用值继续生效，关闭不保存 |

状态按草稿、生效值与最近成功读取或保存的文件值比较，显示“已保存 / 有未应用的更改 / 已应用，未保存”。字段、文件和资源错误分别呈现，反馈跨分类可见；配置已发布或文件已读取后资源失败，保留该事实，不回滚、不报成功。保存失败保留未保存状态。成功提示短暂且不抢焦点；无异步通知不伪造 pending。

外部正式发布配置时，未修改草稿随生效值同步，有草稿则保留并提示变化；用户可放弃或明确再次应用。不声称探测磁盘冲突。宿主 `requestClose` 逐级结束弹层；`requestReload` 清理旧关闭意图及所属选择器后按原确认执行。标签关联字段，图标有可读名称，Tab、ESC、模态与选中状态沿正式语义；样本编辑不产生配置脏状态。

验收使用正式页面、真实输入、文件及资源管线，覆盖跨分类草稿、应用不落盘、保存/重载与注释、空值、错误、重复身份排序、焦点及关闭。Desktop 实机核布局、主题和像素；MC 仅按另行授权验证，不外推桌面结果。
