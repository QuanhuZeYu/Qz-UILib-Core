# 通用设置页模板

业务声明页面标题、分类、字段内容、可编辑性、反馈与操作；模板提供统一导航、正文滚动、字段行和操作栏，复用 Scene、信号、现代外观与正式动效。页头轻量显示页面身份，当前分类标题与说明独立自然测量，字段占剩余空间滚动；分类可声明图标和说明，宽屏导航整行可操作，窄屏复用正式 Select。状态在操作前，次要与主动作按空间对齐或换行，低窗操作仍可滚动到达。标题、主题、语言、字号及密度变化沿正式依赖刷新。

模板不拥有业务配置或持久化，不推断“应用/保存”的先后，不执行文件 I/O；操作标签、资格和动作来自业务。不同分类保留同一份外部草稿，字段错误保留输入并关联字段；关闭及丢弃确认由业务声明，弹层、Tab 与 ESC 沿原范围合同。

提供可组合的字段行与正式布尔、文本、选择控件；文字与控件共用 SceneAppearance 的界面字体、现代 palette 和 editorTheme，文本与选择使用正式字段外表面，布尔说明与右侧 Switch 按可用空间排列，不逐字段套卡片。类型和合法值继续取业务 ConfigKey/schema，不复制默认值和校验规则。自定义对象编辑内容沿同一模板接入，不把所有配置强制降为字符串或 YAML。UILib 自身设置页复用公共区域排列协议，保持原应用/保存合同。

验收使用正式 ScenePageSession、输入、语义与软件绘制，覆盖跨分类草稿、错误保留、业务提交拒绝、动态主题/密度/视口、窄屏操作及重复字段释放；现代工作台层级参考 [Shadcn Admin 设置](https://raw.githubusercontent.com/satnaing/shadcn-admin/main/src/features/settings/index.tsx)及其分类内容组合。游戏和 GPU 效果另行实机取证，不从构建通过外推视觉合格。
