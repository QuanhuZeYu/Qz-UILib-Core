# Qz-UILib Core 5.0.0-beta3

基于 `5.0.0-beta2` 的预发布更新。本次更新重做了共享设置工作区与字体管理交互，提取可复用的公共组件并新增非模态通知系统，补充随包符号字体 `Noto Sans Symbols`，同时修复多项控件渲染与交互细节。

## 主要更新

### 设置工作区与字体管理

- **响应式分类设置页**：重做共享设置页面，采用分类导航与自适应正文布局，窄屏环境下可通过选择控件切换分类。
- **配置状态分层与保护**：跨分类保留同一份草稿，明确区分“未应用草稿”、“已应用但未保存”、“生效值”与“磁盘保存状态”。点击“应用”仅更新当前生效配置而不写文件，“保存”才将生效值写入磁盘；存在未保存更改时，重载与关闭操作均需二次确认。
- **后台异步准备**：文件读写与字体资源准备移至后台执行，完成后回传至对应状态域发布，减少对前台正常交互的阻塞。
- **字体卡片与排序优化**：字体来源改为独立圆角卡片，支持内置字体与本地文件，提供拖放排序、上移/下移、移除与恢复默认操作。扩大排序把手热区，统一弹性重排与取消回落表现；按 `ESC` 或失焦取消时不会改变草稿顺序。
- **样本实时预览**：支持对实际生效字体的预览样本进行编辑与重置，样本改动不写入配置文件。

### 公共组件与通知系统

- **公共组件组合提炼**：提取可复用的布局、弹窗、表单字段、搜索框、选择对话框、主从工作区、反馈及分页组合。设置、邮箱、文件选择与媒体页面已接入复用，支持文案与状态动态更新；共享测试广场同步按组件类别重组，并保留原有综合示例。
- **Toast 与 Notification**：新增轻量提示与非模态通知组件，支持连续堆叠、容量限制、自动结束、持续显示、位置调整及退场动效。`Toast` 不抢夺焦点且不拦截指针事件；`Notification` 支持手动关闭或附带业务操作，出现时不主动抢焦点，关闭与卸载后自动清理所属计时器与绑定。

### 修复与资源

- **渲染与交互修复**：修正文字选区覆盖、弹窗遮罩、输入焦点圆角及字段圆角合成表现；改进文件选择器的正文空间分配、错误反馈与确认交互。
- **动效与测量复用**：统一标准控件动效入口，改善高频输入、拖动与弹性动效场景下的几何计算、测量缓存和绘制复用（不承诺固定帧耗时或性能倍数）。
- **分代字体准备与内置符号字体**：字体按资源代预备默认、具名、数学、UI 与 Unicode 资源，文本测量严格使用准备完成后的资源。新增随包字体 `Noto Sans Symbols 2.001`（保留原始字体、版权、完整 SIL OFL 1.1 许可证与来源说明），默认仅作为 `builtin:noto-symbols` 追加至候选字体列表末尾，优先级仍由现有排序系统决定，不将特定字符强行绑定至该字体。
- **部署诊断**：完善 Maven Central 部署公开操作与终态查询的区分及诊断输出。

## 升级或安装说明

- **版本同步**：请将 Core、Platform、Minecraft 整组同步升级至 `5.0.0-beta3`，避免与旧版本混用。
- **接入方式**：Maven Group ID 继续为 `asia.quanhuzeyu.uilib`，Java 8 环境请使用对应的 `java8` classifier；离线接入请使用同版本 Maven ZIP。
- **存量字体配置提示**：已保存完整 `font.candidates` 列表的用户升级后不会自动获得新增的默认候选字体。如需显示炼金符号等扩展字符，请在字体设置中手动将 `builtin:noto-symbols` 添加至列表末尾（可完整保留已有排序）。
- **开源许可**：项目自有代码继续采用 MIT 许可证；随包分发的 `Noto Sans Symbols` 遵循 SIL OFL 1.1 许可证，其余第三方组件保留各自原有许可。
