# Qz-UILib Core 5.0.0-beta4

新增通用设置模板与 HUD 放置编辑、声明式内容入场、表格外观和分段单选组。统一页签、焦点提示、动态默认值与持久化滚轮距离，修正虚拟行高度、局部测量失效及浮层合批顺序。优化字体匹配、字形缓存与绘制计划复用，提供默认关闭的激进合批选项。

Core、Platform 与 Minecraft 请整组升级至 `5.0.0-beta4`。Maven group 为 `asia.quanhuzeyu.uilib`，Java 8 使用对应 `java8` 制品；离线接入使用同版本 Maven ZIP。Minecraft 玩家安装对应游戏版本的正式宿主包。
