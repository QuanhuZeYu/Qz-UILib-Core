# Qz-UILib-Core 5.0.0-beta1

UILib 5.0 拆分为三个独立仓库：`Qz-UILib-Core`（核心）、`Qz-UILib-Platform`（平台适配与桌面）与 `Qz-UILib`（Minecraft 宿主）。
本版为 `5.0.0-beta1` 预发布；自有代码采用 MIT 许可证，第三方组件保留原许可。

## 主要变化

- **无平台 UI 核心**：提供响应式状态、统一布局、焦点与输入路由及 YAML 配置，可脱离游戏独立运行。
- **现代控件与富内容**：内置虚拟集合、数据表、树视图、标签页、弹层、拖放、弹性动效，支持富文本、Markdown、数学排版与无障碍语义。
- **双 Java 目标与独立验证包**：同步提供 Java 21 默认产物、`:java8` 正式产物及开发源码包；测试广场 `gallery` 与 `core-verification` 独立发布。

## 获取与接入

- **Maven 坐标**：5.0 公开坐标为 `asia.quanhuzeyu.uilib:core:5.0.0-beta1`（Java 8 附加 `:java8`，Java 包名不变，旧 group 仅用于 `4.x`）。
- **离线 Maven ZIP**：可下载 `qz-uilib-core-5.0.0-beta1-maven.zip` 解压到本地，通过 `-PuilibRepository=<本地目录>` 与 `-PuilibVersion=5.0.0-beta1` 接入。
- **宿主验证**：窗口渲染、字体光栅、原生输入与游戏内表现需在下游宿主环境中按实例验证。
