# Qz-UILib Core 5.0.0-beta2

本版补齐 5.0 的许可告知与独立附件装配；自有实现采用 MIT，第三方组件保持各自许可。

## 修复

- 正式 Core 与 Java8 JAR 随附 SnakeYAML 2.4 的重定位修改者、范围及对象文件路径声明。
- 按原始字体内嵌授权，为 Noto Serif 1.03 / Noto Sans 1.04 补充完整 Apache 2.0 及来源说明；保留字体原字节与上游 OFL/元数据。
- gallery 补齐项目 MIT；core-verification 的二进制和源码包随附项目 MIT、Unicode 与 KaTeX 全文及关联通知。

## 接入

使用 asia.quanhuzeyu.uilib:core:5.0.0-beta2，Java8 选择同版本 java8 classifier；离线接入下载本版 Maven ZIP，并将 Platform 与 Minecraft 一并升级到同版本。原 5.0.0-beta1 的补充许可包与更正说明位于其原 Release。

## 验证范围

正式双 Java 目标、开发与源码包、gallery、core-verification 通过完整 build；发布过程的实际提交、运行与资产列于下方构建证据。
